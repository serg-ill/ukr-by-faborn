# Faborn Server · мініадмінпанель

Доступна у серверному пакеті **0.1.0-beta.51**. Потрібно оновити Ubuntu-обробник; звичайні телевізійні логіни й налаштування перегляду зберігаються.

**Нове у beta.48:** логотип F Fold, окрема статистика домашньої мережі, фільтр локальних запитів, зміна пароля адміністратора та власні паролі користувачів.

Панель входить у наявний Node-сервіс. Окремі npm-пакети, контейнер, база даних, CDN та відеопроксі не потрібні. Адреса після ввімкнення: `http://192.168.88.191:8789/admin/` (або фактична локальна адреса й порт сервера).

## Що видно

- **Огляд:** кількість запитів за 30 календарних днів UTC, графік за 7 днів, успішні відповіді, помилки й відмови доступу, звернення до кешу, середній час відповіді, поточні запити до джерела, пам’ять / CPU процесу та час його роботи.
- **Користувачі:** логіни, стан доступу, останній запит / IP, кількість запитів і API-трафік кожного логіна. Створення доступу, новий випадковий пароль, блокування / відновлення, видалення. Пароль і посилання для Lampa показуються лише одразу після створення або зміни пароля.
- **Журнал:** останні 300 запитів із назвою, сезоном / серією, джерелом, результатом, конкретною причиною помилки, часом обробки та обсягом JSON. Окремо — останні 100 входів і дій адміністратора. Максимальний термін зберігання — 30 днів.

**Трафік API** — байти прочитаних JSON-тіл запитів і сформованих JSON-відповідей `/v1/resolve`, включно з помилками. Це не мережевий білінг: HTTP/TCP/TLS-заголовки, відхилені до читання тіла запити, трафік від сервера до сайту й відео не включені. З’єднання, яке закрилося до завершення відповіді, позначається 499; обсяг сформованої відповіді не доводить, що клієнт отримав її повністю.

Відео завантажує сам телевізор. Обробник не знає, чи почалося відтворення, скільки гігабайтів переглянули або хто дивиться зараз. «Обробляється зараз» означає поточні запити до джерела. Для історії перегляду знадобиться окреме передавання подій із плеєра, якого ця версія не додає.

## Джерело та причина помилки — beta.50

У **Журналі** та **Останніх запитах** видно, куди звернувся клієнт: **UAKinogo / Alloha** або **UAFix**. Під HTTP-статусом є пояснення: назву не знайдено, немає другого плеєра, відсутня серія, джерело повернуло HTTP 403 / 404, перевищено час очікування, помилка мережі чи авторизації. Це результат запиту метаданих, а не діагностика декодера телевізора.

**Дані отримано / Дані з кешу** означає лише успішне отримання метаданих. Помилки запуску відео дивіться в діагностиці Faborn на телевізорі: сервер не передає відео й не бачить результат його відтворення.

Подробиці записуються після оновлення сервера. Старі записи збережені, але їхні джерело й причина позначені **Не записано** — відновити їх із самого HTTP-статусу неможливо. У файл статистики потрапляють лише визначений код причини й числовий HTTP-статус джерела; сирі відповіді, підписані URL, токени й паролі не записуються.

## Домашня мережа і паролі — beta.48

- **Огляд → Домашня мережа:** локальні запити, API-трафік і кількість IP за останні 30 календарних днів. Ці запити вже входять у загальний підсумок, їх не потрібно додавати до нього повторно.
- **Користувачі → Домашня мережа:** для кожного IP — останнє звернення, кількість запитів / помилок, отримані й віддані байти, спосіб останнього доступу. Враховуються звернення як без логіна, так і з логіном користувача. Один IP може представляти кілька пристроїв; ця таблиця не визначає особу за адресою.
- **Журнал → Лише локальні:** показує локальні запити, позначені бейджем «Локально». Можна одночасно ввімкнути «Лише помилки».
- **Мій пароль** унизу меню: поточний пароль адміністратора, новий пароль і його повторення. Після збереження всі сесії цього адміністратора анулюються; інші адміністратори й телевізійні логіни залишаються чинними. Забутий поточний пароль можна скинути через SSH, як описано нижче.
- **Користувачі → Змінити пароль:** задайте власний пароль або виберіть «Створити випадковий пароль». Такий самий вибір доступний при створенні користувача. Оновлені пароль і посилання для Lampa показуються один раз; після зміни потрібно оновити дані на відповідному телевізорі.

Власний новий пароль у панелі має містити від 8 символів до 256 байтів UTF-8, без керівних символів. Старі паролі не змінюються автоматично. Панель не дозволяє подивитися збережений пароль: у файлах залишаються лише scrypt-хеші. Журнал фіксує факт зміни без пароля.

Локальність визначається реальною TCP-адресою: мережі `FABORN_ALLOW_LAN`, `FABORN_ADMIN_LAN` та loopback. Ця позначка сама по собі не надає доступу без пароля. Публічна адреса через NAT може бути видима серверу як адреса роутера — точність поділу обмежена тим, яку адресу бачить TCP-сокет.

Статистика починається з моменту встановлення панелі; звернення, які телевізор обслужив зі свого кешу або через інше джерело, сервер не бачить. Завантаження самої панелі, її опитування та `/health` не збільшують лічильник запитів до обробника. При оновленні старі локальні підсумки зберігаються без вигаданого розподілу за IP; поділ за адресами накопичується з нових запитів. На добу зберігається до 160 локальних адрес, загальні підсумки враховують і звернення понад цей ліміт.

## Доступ

Панель **вимкнена за замовчуванням**. З Mac підключіться до домашнього Ubuntu:

```sh
ssh USERNAME@192.168.88.191
```

У відкритій SSH-сесії завантажте інсталятор beta.50. Приклад нижче зберігає ваш порт `8789` і вмикає панель лише в домашній мережі:

```sh
curl -fL https://raw.githubusercontent.com/serg-ill/ukr-by-faborn/v0.1.0-beta.51/server/uakinogo/install.sh -o /tmp/faborn-install.sh &&
sudo bash /tmp/faborn-install.sh --port 8789 --admin-lan 192.168.88.0/24
```

Інсталятор створює окремий `admin` із випадковим паролем і друкує його один раз у терміналі. Повторне встановлення зберігає пароль. Наявні логіни друзів, правила локального доступу, порт і ключі залишаються такими, як були. Інсталятор розпізнає також `--admin-lan none`: вимкнути панель, зберігши файли.

Адмінпанель перевіряє реальну адресу TCP-з’єднання: дозволена лише задана приватна IPv4-мережа та loopback. `X-Forwarded-For` / `X-Real-IP` не враховуються. Звертайтеся за IP сервера або `localhost`; довільні доменні імена та зворотний проксі в цій версії не підтримуються. Правило переадресації 8789 на роутері не дає зовнішньому клієнту доступу до адмінки.

Окремий пароль адміністратора обов’язковий навіть із увімкненим `--allow-lan`. Звичайні логіни, Bearer-ключі та дозвіл локального перегляду не відкривають адмінку. Сесія закінчується після 30 хвилин бездіяльності або максимум 8 годин; видима панель із автооновленням підтримує активність сесії. Вихід, зміна пароля адміністратора та перезапуск сервера анулюють сесію.

Локальна панель використовує HTTP на наявному порту. Вона не налаштовує доступ із публічного інтернету. Для віддаленого керування потрібен окремо продуманий захищений канал.

## Файли й обслуговування

```ini
FABORN_ADMIN_LAN=192.168.88.0/24
FABORN_ADMIN_FILE=/opt/faborn-resolver/auth/admin.json
FABORN_STATS_FILE=/opt/faborn-resolver/state/metrics.json
```

Ці параметри зберігаються в `/etc/faborn-resolver.env`. Адміністратор і глядачі повинні мати різні файли. Користувач systemd `faborn-resolver` може писати лише у `auth` та `state`; код випуску залишається захищеним від запису. Для нестандартних шляхів власник налаштовує права й `ReadWritePaths` самостійно.

Паролі — salted scrypt, а не відкритий текст. Статистика не містить заголовків авторизації, паролів або підписаних посилань на відео. Зберігаються IP та запитані назви, доступні лише адміністратору. Дані записуються атомарно раз на 30 секунд і при штатній зупинці; аварійне вимкнення може втратити останні 30 секунд. Пошкоджений файл статистики зберігається для відновлення, панель показує помилку, нові дані тимчасово збираються в пам’яті.

Скинути забутий пароль адміністратора через SSH:

```sh
sudo /opt/faborn-resolver/node/bin/node \
  /opt/faborn-resolver/current/server/uakinogo/users.js \
  --file /opt/faborn-resolver/auth/admin.json reset admin --generate
```

Блокування логіна діє на наступні авторизовані запити. Воно не зупиняє вже відкрите відео й не скасовує доступ без пароля для дозволеної LAN. Скидання пароля заблокованого логіна не розблоковує його. Видалення останнього користувача не вимикає авторизацію.

## Перевірка перед випуском

```sh
node --test tests/test_uakinogo_admin.js tests/test_uakinogo_auth.js tests/test_uakinogo_server.js tests/test_uakinogo_installer.js
bash -n server/uakinogo/install.sh
```

У серверний архів потрібно включити весь каталог `server/uakinogo`, зокрема `admin/`, `admin.js`, `network.js`, `metrics.js`, та наявний `lib/4klab/core.js`. Автоматичні перевірки й локальний браузер не замінюють перевірку встановлення на Ubuntu з systemd.
