# Перевірка 0.1.0-beta.2 — 30 вересня 2026

## Причина виправлення

Користувач повідомив про нескінченне завантаження «Бджоляра» у 1080p на Samsung. У старому опублікованому індексі маніфести цього релізу відкривалися, але перший відеосегмент повертав HTTP 404 для 2160p, 1080p, 720p і 480p. Сторінка Ashdi видала новий шлях; усі чотири нові варіанти повернули перші байти сегмента з HTTP 206. Це підтверджена несправність старих посилань, але не доказ єдиної причини на конкретному телевізорі.

Індекс beta.1 зберігався в пам’яті без строку дії, а Actions оновлював його раз на 6 годин. Beta.2 читає опублікований індекс перед ручним запуском, обмежує кеш списку хвилиною та запитує оновлення Actions кожні 30 хвилин. Оновлення Pages не дорівнює миттєвому отриманню нових адрес від Ashdi.

## Виконані перевірки

- 33 автоматичні тести: 10 Python та 23 Node.js, усі пройшли.
- Регресії: заміна закешованої адреси перед стартом, відмова від нового недоступного запису, скасування запиту, помилка AVPlay, зависання старту 45 секунд, підготовлене/відтворюване відео та плеєр іншого розширення. Нативний Tizen у цих тестах модельований.
- Acorn 8.18.0: синтаксис ES5; схема індексу: 3 назви, 18 записів.
- Локальна сторінка зі справжнім ядром Lampa: кнопка розширення, номер beta.2, зіставлення «Бджоляра», український реліз, 4K/1080p/720p/480p та повідомлення про обмеження браузерного плеєра. Використано тестову картку з подією full/complite.
- Оновлений індекс: 2026-09-29T21:41:18Z; успішно оновлено 18 потоків, помилок 0. Перевірено маніфести й початок першого сегмента найвищої якості кожного потоку. Окремо перевірені всі чотири якості двох тестових фільмів.
- Контрольні суми файлів пакета: SHA256SUMS.txt. JSON на Pages оновлюється після пакування і може відрізнятися.

## Межі

- Відтворення виправленої версії на фізичному Samsung ще не підтверджене. Потрібна повторна перевірка після заміни URL розширення та повного перезапуску Lampa.
- Вебплеєр Lampa залишається несумісним із CORS відеосегментів Ashdi. Потрібен шлях Tizen / AVPlay.
- Індекс містить лише три назви. Повного пошуку по каталогах сайтів немає.
- Нові адреси потрапляють на телевізор після успішної публікації Actions. GitHub може затримувати розклад; кнопка оновлення в Lampa не запускає серверне збирання.
- Таймер обмежує початковий запуск до події loadeddata або руху часу відео. Він не стежить за кожним подальшим буферизуванням.
- URL наступних серій уже відкритого плейлиста є знімком на момент запуску. Якщо адреса змінилася під час перегляду, серію потрібно повторно відкрити через розширення.
