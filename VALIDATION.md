## Справжній інтерфейс Lampa

Локальна QA-сторінка використовує офіційний bundle Lampa та подію `full/complite` для тестової картки. У production JS тестових перенаправлень немає.

1. Прямий реальний запит із браузерної Lampa: показано «UAKino · не вдалося завершити», етап «Пошук UAKino», причина «Мережа / CORS / TLS: HTTP-статус недоступний». Екран завантаження завершився; діагностика відкрилася й показала beta.4 та цей етап.
2. На локальних тестових відповідях у тому самому справжньому UI пройдено: картка «Джанґо вільний» → «Знайти на UAKino» → результати з роками 1966/2012 → вибраний фільм → «Український дубляж» → меню якості. 4K у цьому UI-сценарії задано синтетичним HLS для перевірки парсера; це не твердження про 4K реального релізу Django.
3. Передачу нового фільму до Player.play та вибраної серії перевірено моделлю Tizen API у Node. Вона не замінює AVPlay і фізичний телевізор.

## Спостереження щодо джерела

У звичайному браузері відкрита головна UAKino, через її форму отримано результати запиту «Джанґо», прочитано сторінку Django та посилання Ashdi `/vod/3306`. Сторінка «Джек Річер, сезон 3» показала `inLanguage=uk`, метадані озвучення та контейнер `playlists-ajax` із ID сторінки. Скорочені фікстури зберігають лише потрібну розмітку; опис сюжету не копіювався.

Безпосередні CLI-запити до UAKino повертали 403. GET-URL пошуку у браузері показав перевірку Cloudflare; модуль використовує POST публічної форми `/ua/`. CORS-доступ до цієї форми з браузерної Lampa не підтверджено. Публічний формат запиту AJAX-списку звірено з [відкритим адаптером UAKino](https://github.com/Nightmare84/repository.nightmare/blob/HEAD/matrix/plugin.video.uakino.club/site_parser.py); звичайна навігація до endpoint повернула `error`. У модулі використовується AJAX-запит із `X-Requested-With: XMLHttpRequest`. **Успішний мережевий прохід цього етапу ще не підтверджений**; його парсинг перевірено фікстурою. Невідомий або заборонений формат завершується явною помилкою.

## Межі нової бети

- Користувач підтвердив роботу попереднього відтворення beta.3. Новий пошук beta.4 ще не перевірений на фізичному Samsung. Його мета — перевірити прямий доступ саме з установленого застосунку Tizen.
- Модуль не обходить Cloudflare, CORS чи TLS. Невдала спроба з одного оточення не доводить відмову в іншому.
- У прямому режимі підтримано відкритий HLS Ashdi, а наступна серія вибирається вручну. Вкладені JSON-плейлисти Ashdi й інші відеохости ще не підтримані.
- Якість і мова беруться з даних джерела; звук не розпізнається автоматично, HDR не вгадується. Повний відеофайл у перевірках не завантажувався.
- Старий індекс має окреме оновлення Actions. Дати джерел у committed JSON не підмінено новою датою: їх актуалізує workflow після публікації.
