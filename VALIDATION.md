# Перевірка 0.1.0-beta.3 — 30 вересня 2026

## Підтверджена помилка

На фото з телевізора відкриття налаштувань завершується `Cannot read property '' of undefined`, `update$3`, `app.min.js:47632:67`. Ту саму помилку відтворено на локальній сторінці зі справжнім ядром Lampa. Файл за URL зі стека також перевірено: цей рядок читає `values[name][key]`.

Причина в розширенні: поле `faborn_ukr_pages` з типом `input` не передавало `values` до `Lampa.SettingsApi.addParam`. Для текстового поля Lampa очікує рядок. Додано `values: ''` і зрозумілий текст порожнього значення. Ядро Lampa не змінювалося.

## Виконані перевірки

- 37 автоматичних перевірок: 10 Python та 27 Node.js, усі пройшли.
- Додано регресії контракту текстових налаштувань, відкриття діагностики з картки, нативної помилки `event.error` та пізньої помилки від попереднього плеєра.
- Acorn 8.18.0: синтаксис ES5. Схема індексу: 3 назви, 18 записів.
- Справжнє ядро Lampa, до виправлення: падіння в `update$3` на тому самому рядку 47632:67.
- Справжнє ядро Lampa, після виправлення: відкриваються всі налаштування модуля, поле адреси показує «Визначається автоматично», видно номер beta.3.
- Кнопка «Версія та діагностика» працює з налаштувань і з меню модуля в тестовій картці «Бджоляра». Перевірка картки використовує подію `full/complite` зі справжнім UI Lampa.
- Контрольні суми файлів пакета — у `SHA256SUMS.txt`. Публікація GitHub Actions повторно перевіряє код, оновлює потоки та перевіряє схему індексу.

## Діагностика плеєра

Адаптер Tizen у Lampa передає нативну помилку як `event.error`. Загальний обробник відео натомість читає `video.error`; через це частина помилок не доходить до `Lampa.PlayerVideo.listener`. Beta.3 додатково підписується на помилку об’єкта відео після події `Player.ready`, тільки для власного запуску. Обробники AVPlay та глобальні налаштування плеєра не замінюються. Перехоплення перевірено моделлю API, без фізичного телевізора.

Версія, вибраний плеєр, доступність AVPlay API та збережена помилка розташовані на початку діагностики. Також зберігається назва й якість останньої спроби запуску. Дані залишаються в локальному сховищі Lampa, на зовнішній сервер не надсилаються.

## Межі

- Виправлення падіння налаштувань підтверджено. Відтворення відео на фізичному Samsung поки не підтверджене; причина нескінченного завантаження на ньому ще потребує показників діагностики.
- Помилки, які виникли до події `Player.ready`, можуть не потрапити до додаткового нативного обробника. Таймер beta.2 залишається страховкою початкового запуску після події `Player.start`.
- Таймер завершується після `loadeddata` або руху часу відео, не стежить за кожним наступним буферизуванням.
- Браузерний плеєр залишається обмежений CORS сегментів Ashdi. У тестовій браузерній діагностиці очікувано показано `inner` та недоступний AVPlay API.
- Індекс містить лише три назви. Оновлення Actions може затримуватися; кнопка читання індексу не запускає його серверне збирання. Адреси наступних серій плейлиста залишаються знімком на момент запуску.
