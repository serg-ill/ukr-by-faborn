Повний `open()` → пошук → перевірка сторінки → параметри плеєра → сесія → список → HLS → передавання `Lampa.Player.play` виконано з живими HTTP-запитами й імітованим API Lampa: «Термінатор 2», 2160p RU (20 запитів); «Друзі», S1E1, 720p UA (13 запитів). Оригінальна назва «Friends» знаходить серіал після відбору за роком і типом. Це підтверджує код пошуку та переданий URL, а не декодування AVPlay.

Для 4K з окремим аудіо збережено master-плейлист; відеоваріант без аудіогрупи окремо не передається. Дзеркала не збільшують кількість рядків озвучень.

## Справжнє ядро Lampa
