Резервний тестовий індекс
«Бджоляр» (2024), «Профі» (2025), «Джек Річер» — сезон 3, серії 1–8 у DniproFilm та Uaflix. Це не повні каталоги сайтів.

Для перевірки на Samsung обери плеєр Tizen / AVPlay у Lampa. Сегменти Ashdi блокуються CORS у браузерному плеєрі. Попередня beta.3 вже відтворює відео за відгуком користувача. Новий прямий пошук beta.4 потребує перевірки на телевізорі.

  • Фільми: 4K / 1080p / 720p / 480p, якщо потік доступний.
  • Серіали: озвучення та вибір епізоду. У прямому пошуку наступну серію поки обирай вручну.
  • Відео надходить з Ashdi. GitHub розміщує розширення й індекс.

Якщо сайт недоступний, модуль покаже етап і причину. Пункт «Версія та діагностика» зберігає результат останніх запитів.
