0.1.0-beta.55 · Lampa / Tizen · GitHub Pages
beta.55: без системного вікна входу.
Відмова сервера показується у стані джерела; повторні фонові запити зупиняються до зміни налаштувань або ручного повтору. Прямі джерела працюють без логіна Faborn. Для усунення браузерного запиту пароля оновіть Ubuntu до beta.55 за інструкцією. Наявні користувачі, паролі, порт і журнал зберігаються.
beta.54: окремий захищений DNS для Alloha.
Для перевірки проблем із DNS: Faborn → UAKinogo · сервер → Захищений DNS для Alloha → Увімкнено · Cloudflare. Опція початково вимкнена й діє з наступного запуску Alloha; відео надходить напряму. Повністю перезапустіть Lampa; сервер оновлювати не потрібно. Режим не обходить блокування IP. Перевірка мережі та телевізора тестера залишається потрібною.

Додай цю адресу в Lampa: Налаштування → Розширення → Додати.

Уже встановлено? Повністю перезапусти Lampa. Посилання змінювати не потрібно.

beta.52: підготовка Alloha й тайм-аути.
Оновлення сесії та скасування обробляються між мережевими запитами. Помилка показує конкретний етап. Повністю перезапустіть Lampa. Сервер beta.50 / beta.51 сумісний; перевстановлення Ubuntu не потрібне. Перевірка Alloha 4K на проблемному Samsung ще потрібна.
beta.51: виправлення запуску Alloha.
Усунено регрес beta.50 — Illegal invocation під час підготовки 4K. Повністю перезапустіть Lampa. Сервер beta.50 сумісний; перевстановлювати Ubuntu не потрібно. У діагностиці HLS — точніша причина помилки. Для локального журналу перезавантажте адмінпанель і відкрийте «Журнал → Лише локальні». Фізична перевірка на Samsung залишається потрібною.
beta.50: Alloha та зрозумілий журнал.
Виправлено підтримку сесії Alloha після HTTP 403 CDN. У серверному журналі — джерело й конкретна причина помилки. «Дані отримано» стосується метаданих, а не запуску відео. Оновіть Ubuntu та перезапустіть Lampa. Оновлення й подробиці журналу. Відео через Ubuntu не передається; запуск на фізичних Samsung після зміни ще потребує перевірки.
beta.49: завантаження джерел та сумісність плеєра.
Виправлено визначення GitHub Pages після запуску з кешу. Для KinoBase H.264 у 4K на Tizen 3 додано шлях через AVPlay за ввімкненого «4K на старому Tizen». UAFix після 404 може отримати конфігурацію через серверну бету; відео йде напряму. Перезапустіть Lampa та оновіть Ubuntu за інструкцією. Фізичний запуск 4K потребує перевірки; Alloha без WebAssembly залишається недоступною.
beta.48: нова F та зручніша адмінпанель.
Логотип F Fold у кнопці запуску, налаштуваннях, вікнах джерел, на сайті й у серверній панелі. Домашні запити й IP — в окремій статистиці та фільтрі журналу; «Мій пароль» для адміністратора, власні або випадкові паролі користувачів. Перезапустіть Lampa. Для доповнень панелі оновіть Ubuntu за інструкцією. Наявні порт, логіни й статистика зберігаються.
beta.47: мініадмінпанель сервера.
Логіни, створення доступу для друзів, блокування, нові паролі, запити, помилки й API-трафік — у браузері. Окремий пароль адміністратора, доступ із домашньої мережі. Встановлення панелі на Ubuntu. Для цієї функції потрібне оновлення сервера; порт, користувачі й налаштування Lampa зберігаються. Відео через Ubuntu не передається.
beta.46: обирайте мову, а модуль — найкращу якість.
Над якістю: Українська · English · Російська · Усі мови. Типово українська. Найкраща показує кожне озвучення на його максимальній якості; українські 1080p не губляться через англійські 4K. Якість видно біля озвучення, джерела й у кнопці запуску. Перемикання без повторного пошуку; коли мови немає — явне повідомлення й «Показати всі мови». Працює в усіх трьох оформленнях. Перезапустіть Lampa; Ubuntu для цього оновлювати не потрібно.
beta.45.1: виправлено локальне підключення.
Прибрано підставлену підказку test1; порожній логін показує «Не задано». У UAKinogo · сервер є Очистити логін і пароль. Для домашнього доступу без пароля потрібне оновлення Ubuntu із --allow-lan 192.168.88.0/24; зовнішні клієнти зберігають авторизацію. Команда оновлення та налаштування.
beta.45: плеєр у стилі Lampa, компактні налаштування та вхід на сервер.
Faborn Player: повноширинна шкала, час, пауза по центру, якість / субтитри / озвучення праворуч. Робочий браузерний HLS збережений. У налаштуваннях — 8 головних пунктів, попередні значення збережені, фон без живого розмиття. Перегляд і джерела містить вибір плеєра й механізму HLS; UAKinogo · сервер — адресу, логін і пароль. Для авторизації оновіть Ubuntu з --test-users: створяться test1 і test2 з випадковими паролями у приватному терміналі. Облікові записи та інструкція. Відео надходить прямо на телевізор.
beta.44: браузерний бета-плеєр для Alloha.
Налаштування → Faborn → Перегляд і джерела → Плеєр онлайн → Faborn Player · бета, потім Механізм бета-плеєра → Браузерний HLS · бета. Типовий механізм — Samsung AVPlay. Збережені якість, озвучення, пауза, перемотування, прогрес і Back; бібліотека завантажується лише при запуску цього режиму. Діагностика показує фактичне джерело, механізм та HTTP-код. Після beta.44 користувач підтвердив запуск браузерного HLS на Samsung; нове оформлення ще потрібно перевірити на телевізорі. Для нового входу за логіном і паролем оновіть Ubuntu до beta.45.
beta.43: повернення після помилки та бета-плеєр UAKinogo.
Back повертає кешовані джерела й керування. UAKinogo враховує «Налаштування → Faborn → Перегляд і джерела → Плеєр онлайн → Faborn Player · бета»: перемикання якості, озвучення та спільний прогрес. Переустановлення Ubuntu не потрібне. Фізичний запуск 4K AV1 цим шляхом ще потребує перевірки.
beta.42: галочка, клавіатура та перевірка каналу UAKinogo.
Галочка замість «Перегля…» у картці; спрощені ефекти клавіатури й кешування прогресу. Перед AVPlay перевіряється локальний HLS; виправлений порядок закриття після помилки. Нові рядки діагностики покажуть стан каналу. Ubuntu beta.40 / beta.41 сумісний, переустановлення не потрібне. Відтворення 4K на фізичному Samsung ще потрібно перевірити.
beta.41: виправлено HTTP 413 UAKinogo, до трьох студій у картці.
Ubuntu отримує лише потрібні дані назви замість усієї картки TMDB. Установлений сервер beta.40 сумісний: достатньо перезапустити Lampa, переустановлення не потрібне. Помилки запиту показують конкретну причину. Три студійні бейджі залишаються в одному рядку без «+N».
beta.40: KinoBase та окрема серверна бета UAKinogo.
Повільна відповідь KinoBase доповнює список без повторного відкриття. UAKinogo типово вимкнений; Ubuntu отримує лише посилання, відео йде прямо на телевізор. Інструкція встановлення Ubuntu.
beta.39: усі студії в один рядок і менше зайвих оновлень інтерфейсу.
У картці кожна студія має власний бейдж: без «+N» і без переносу. Дата, віковий рейтинг і статус залишаються поруч.
Прибрано повторну перебудову незмінених бейджів під час навігації, скорочено роботу обробників прогресу й карток. Рейтинги, якість та позначки перегляду оновлюються при зміні даних.
beta.38: окремий бета-плеєр, чорні бейджі студій і правка верхньої панелі.
Спробувати плеєр: Налаштування → Faborn → Перегляд і джерела → Плеєр онлайн → Faborn Player · бета. Типово залишається Lampa. Бета використовує Samsung AVPlay: пауза, перемотування, вибір якості / озвучення / субтитрів, спільний прогрес, наступна серія та повернення до знайдених джерел.
Усі сім бейджів студій чорні в кожній темі, з контрастними фірмовими логотипами. У верхній панелі прибрані ефекти, які могли спричиняти мерехтіння фону.
Бета-плеєр потребує перевірки на телевізорі: проблемне 4K на старому Tizen ще не підтверджено. Пропуск вступу / титрів поки доступний у звичайному плеєрі Lampa.
beta.36: сортування серіалів і виправлення iOS.
У меню «Серіали» для TMDB: популярні з 100+ оцінками, усі країни. Над постерами — сортування, поріг оцінок, країна й тип телепроєкту; вибір зберігається. Повернути штатний каталог: Налаштування → Faborn → Каталог серіалів → Звичайна Lampa.
Коротка назва «Медіатека», пауза у формі кнопок iOS, відцентровані літери клавіатури. KinoBase більше не показує загальний перелік озвучень як одну доріжку епізоду; відсутність збігу назви відокремлена від помилки доступу.
beta.35: компактна картка, новий плеєр iOS і повтор KinoBase.
Рейтинги та реакції поруч; дата, студії, вік і статус — одним рядом після якості. В iOS — темні скляні панелі плеєра з окремим регулятором «Прозорість плеєра iOS» у налаштуваннях Faborn.
За помилки підключення KinoBase автоматично пробує запасну адресу тієї самої серії, якості й озвучення, зберігаючи час. Результат — у діагностиці «Потік KinoBase».
beta.34: дата та студії зверху.
Одразу після якості — бірюзовий бейдж дати та сині й фіолетові бейджі студій із більшими підписами та логотипами. Для серіалів — дата прем’єри й канал / сервіс, якщо він відомий; для фільмів — реліз і виробники.
До двох назв і «+N» для решти; повний список виробників залишається в деталях. Нижня дата не дублюється. Працює у Faborn, iOS та стандартній Lampa.
beta.33: твоя медіатека.
«Мої серіали» тепер — «Медіатека» із вкладками Фільми / Серіали. Фільми поділено на «Хочу подивитися» та «Переглянуто»; бажані завжди першими. Додавай іконкою в картці, із пошуку або історії; довге OK змінює групу.
Після 80% перегляду фільм автоматично додається до «Переглянуто», навіть якщо його раніше не було в медіатеці. Для онлайну й торрентів із карткою та прогресом Lampa. Збережені серіали й прогрес залишаються.
Налаштування → Faborn → Коментарі в картці: лише джерела, лише Lampa, усі або приховати всі. Початково — лише джерела; попереднє явне вимкнення джерел зберігається.
beta.32: власні коментарі з джерел.
Під описом фільму або серіалу — компактні картки відгуків UAFix та UASerials: автор, дата, реакції та позначення сайту. OK відкриває повний текст, Назад повертає на той самий коментар. Позначені сайтом спойлери приховані до окремого підтвердження.
Відгуки завантажуються при переході до ряду; до 24 коментарів із перших сторінок джерел, кеш та кнопка оновлення. У beta.33 налаштування: Налаштування → Faborn → Коментарі в картці. Після зміни повторно відкрий картку.
beta.31: компактні коментарі.
У картці — компактні прев’ю з автором і реакціями, до чотирьох рядків тексту та підказкою «OK — читати». На тестовому екрані 1280×720 вміщуються три повні коментарі. OK відкриває весь текст, Назад повертає фокус.
Кольори підлаштовуються під Faborn, iOS або стандартну Lampa. Окремий список повних коментарів зберігає штатне оформлення.
beta.30: помітні сторінки та швидші «Мої серіали».
Над картками й під списком — великі «Попередня сторінка» / «Наступна сторінка», номер сторінки та діапазон серіалів. Наступна сторінка виділена акцентом твоєї теми. Після переходу пульт одразу вибирає перший серіал.
Менше повторних підрахунків історії й перебудов списку: дані відкритих сторінок використовуються повторно, змінюються лише потрібні частини карток. Після нових відміток, зміни профілю чи календарного дня прогрес оновлюється.
beta.29: переглянуте та перенесення прогресу.
Мої серіали → Переглянуте: позначити все, що вже вийшло, окремий сезон або серії до вибраної включно. Перед збереженням — кількість епізодів; майбутні серії залишаються непроглянутими. Є «Скасувати останні відмітки». Після завершення поточного сезону — «Очікуємо нових серій».
Перенести з іншого профілю копіює локально збережені відмітки та список Faborn без перезапису поточного прогресу. Видалений кеш або дані з іншого пристрою відновити цим способом не можна.
Також доступно: Налаштування → Faborn → Переглянуте та перенесення.
beta.28: «З початку» та нові серії.
У панелі плеєра — кругова стрілка «З початку · 00:00» поруч із Play / Pause. У вікні джерел теж є «З початку», коли збережений прогрес, зокрема для завершеного відео.
У картці серіалу й «Моїх серіалах» — сьогодні / завтра / через N днів, сезон, серія й дата. Для серіалів із власного списку — сповіщення без повторів після повернення з відео. Перша перевірка запам’ятовує поточний стан; наступні — раз на 6 годин, поки працює Lampa.
Налаштування → Faborn → Відлік до нової серії / Сповіщення про нові серії — незалежні перемикачі. Дата TMDB не означає наявності потрібного озвучення.
beta.27: «Мої серіали» та «Що подивитися».
Дві окремі вкладки в боковому меню. «Що подивитися» добирає три фільми за настроєм, часом і рейтингом. «Мої серіали» показує останній епізод, прогрес і дати нових серій.
Картка серіалу → «+» → серіал у твоєму центрі. Іконка зміниться на «✓»; повторне натискання дозволяє відкрити центр або прибрати серіал без втрати історії. У центрі також є пошук і додавання з історії.
Показ вкладок: Налаштування → Faborn → Вкладка «Мої серіали» / «Що подивитися». Метадані й дати — TMDB; доступність потоку перевіряється у картці.
Акваріуми прибрані.
Обидва варіанти видалені; попередній вибір акваріума автоматично змінюється на Аврору. Час запуску та налаштування годинника зберігаються.
Картка → іконка F Faborn → переклад → плеєр.
Пошук на UAKino, UASerials, UAFix та KinoBase виконується автоматично. Угорі — вибір якості, нижче — переклади без повторів для кожного джерела.
beta.24.1: відновлення автопереходу серій.
Модуль відновлює чергу серій при запуску. Якщо після завершення відео Lampa не почала наступну серію, модуль оновлює та перевіряє її потік і повторює перехід. Зберігаються озвучення й вибір якості. У «Версії та діагностиці» додано стан автопереходу та версію Lampa.
beta.24: мітки джерел і компактний хедер.
Налаштування → Faborn → Пропуск за мітками джерела (початково вимкнено). Мітки конкретного потоку мають пріоритет, за їх відсутності залишається налаштований IntroDB. Кнопка «Пропустити фрагмент»: 7 секунд, OK — зараз, Назад — скасувати. Без придатних міток час не вгадується.
Хедер джерел компактніший приблизно на 20%, без зайвої градієнтної рамки; кнопка закриття зберігає розмір.
beta.23: наступна серія та пропуск за мітками.
Автоперехід зі збереженням озвучення; «Назад» повертає до джерел без нового пошуку. У налаштуваннях модуля — окремі «Пропуск вступу за мітками» та «Пропуск титрів за мітками» (початково вимкнені). Кнопка з відліком 7 секунд з’являється лише на мітці конкретного відео. OK — пропустити, Назад — скасувати. Без міток нічого не пропускається.

Три оформлення: «Панель», «Кінозал» та «Стандартне Lampa». Перемикаються в Налаштування → Faborn → Оформлення модуля. «Стандартне Lampa» повертає штатні вікна й фокус у всій системі, без кольорових акцентів та градієнтів Faborn. Застосовується одразу; при поверненні до «Панелі» або «Кінозалу» відновиться обраний колір.

Для «Панелі» та «Кінозалу» доступні тема всієї Lampa, чотири суцільні акценти й два градієнти: синій → фіолетовий та бірюзовий → синій. Якість, переклади та кнопки джерел зібрані в одному вікні. Якщо джерело одне — переклад запускається одразу. Для серіалів є окремі кнопки сезону й серії.

Серії: назви, кадри й прогрес. Натисни «Серія …», щоб побачити епізоди з TMDB і позначки перегляду. «Ви дивилися S…E…» повертає до останнього перегляду. Субтитри вибираються кнопкою CC у плеєрі, якщо вони доступні в джерелі.

KinoBase — постійне джерело. Українські доріжки — UA, російські — 🐷 RU. Українські показуються першими в обраній якості. Для серіалів доступні сезони й серії; якість залежить від конкретного релізу.

  • 4K / 1080p / 720p / 480p — залежно від потоку.
  • Кнопка «Назад» повертає керування картці.
  • Потрібен плеєр Tizen / AVPlay у налаштуваннях Lampa.

UAKinogo · серверна бета — вимкнена за замовчуванням. Окремий обробник Ubuntu отримує посилання; відео надходить на телевізор. Доступ за логіном і паролем із beta.45. Інструкція встановлення. Потрібні Tizen Sockets та підтримка вибраного AVPlay або браузерного HLS і кодека потоку.

Раніше окремими HTTP-перевірками з cookie підтверджено «Оппенгеймер» — UA LeDoyen 4K, «Термінатор 2» — 4K, «Назад у майбутнє» — Full HD, «Друзі» — 720p з UA 1+1 та RU.
