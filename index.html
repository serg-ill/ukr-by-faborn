Картка → ukr by Faborn → переклад → плеєр.
Пошук на UAKino, UASerials, UAFix та KinoBase виконується автоматично. Угорі — вибір якості, нижче — переклади без повторів для кожного джерела.

Два оформлення: «Панель» та «Кінозал». Перемикаються в Налаштування → ukr by Faborn → Оформлення модуля. Там само — тема всієї Lampa, чотири суцільні акценти та два градієнти: синій → фіолетовий і бірюзовий → синій. У beta.9 кольори яскравіші й насиченіші.

Якість, переклади та кнопки джерел зібрані в одному вікні. Якщо джерело одне — переклад запускається одразу. Для серіалів є окремі кнопки сезону й серії. Тему можна вимкнути незалежно від вигляду модуля; стандартний список залишено для сумісності.

KinoBase тепер є постійним джерелом. Українські доріжки — UA, російські — 🐷 RU. Українські показуються першими в обраній якості. Для серіалів доступні сезони й серії; якість залежить від конкретного релізу.

  • 4K / 1080p / 720p / 480p — залежно від потоку.
  • Кнопка «Назад» повертає керування картці.
  • Потрібен плеєр Tizen / AVPlay у налаштуваннях Lampa.

Версія й діагностика: Налаштування → ukr by Faborn → Версія та діагностика. Має бути 0.1.0-beta.9.

У KinoBase перевірено HLS: «Термінатор 2» — 4K, «Назад у майбутнє» — Full HD, «Друзі» — 720p з UA 1+1 та RU. Підтримано прямий плеєр; сторонні iframe-балансери поки недоступні. Фізичний Tizen для нового джерела ще потребує перевірки.

Недоступні плеєри не потрапляють до списку готових потоків. На 30.09.2026 перевірені плеєри UAFix / Zetvideo для двох назв відповіли 404. Потоки UASerials для «Проєкт Аве Марія» й «Ззовні» віддали 1080p; ці перевірки стосуються доступності потоку, а не декодування на телевізорі.

GitHub розміщує модуль і резервний індекс. KinoUkr додається з резервного індексу; прямого пошуку цього сайту немає. Наступна серія поки вибирається вручну.
