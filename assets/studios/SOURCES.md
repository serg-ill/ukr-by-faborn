# Логотипи сервісів

Використовуються для впізнавання добірок відповідних сервісів у Lampa. Торговельні марки належать їхнім власникам.

Перевірено 2026-10-04:

- **HBO Max:** `hbo.svg` — незмінений офіційний SVG `HBO_Max_Vert_W_RGB`, білий вертикальний логотип із [бренд-сторінки HBO Max](https://brand.hbomax.com/logos). [Оригінальний файл](https://cdn.prod.website-files.com/6911e6b4bcc8af690d496a26/6911e6b4bcc8af690d496df3_HBO_Max_Vert_W_RGB.svg). Замінює застарілий горизонтальний логотип у блоці головної. Колір білий для темного тла; пропорції збережені.
- **Apple TV:** чорний локальний знак показується білим на темному тлі, без зміни форми. [Офіційна назва й матеріали Apple TV](https://www.apple.com/tv-pr/about/).
- **Disney+:** `disney-white.png` — незмінений прозорий білий логотип із футера [Disney+](https://www.disneyplus.com/). [Оригінальний файл](https://cnbl-cdn.bamgrid.com/assets/90b70e482fdbaaf3eb114649007158a4951d89270cba5e00da4fab657d420865/original).
- **Prime Video:** `prime-white.png` — незмінений прозорий білий логотип зі стрілкою з [Prime Video](https://www.primevideo.com/). [Оригінальний файл](https://m.media-amazon.com/images/G/01/digital/video/acquisition/logo/pv_logo_white._CB548637580_.png).
- **Paramount+:** `paramount-white.png` — незмінений прозорий білий знак із горою та написом із [Paramount+](https://www.paramountplus.com/). [Оригінальний файл](https://www.paramountplus.com/assets/images/intl-landing-page/pplus_marketing_site_logo_white.png).
- **Netflix / Hulu:** локальні червоний / зелений логотипи залишаються без перефарбування.

Усі сім бейджів мають однакове чорне тло (`#000`) у кожній темі Lampa, включно з фокусом. Світлі логотипи читаються на чорному без перефарбування; фокус позначається контуром теми. Netflix лишається червоним, Hulu зеленим.

PNG Apple TV, Netflix і Hulu успадковані з попередніх випусків; ця правка не заявляє нове походження цих файлів. Старі файли інших логотипів збережені для попередніх версій клієнта. Логотипи завантажуються з GitHub Pages розширення, без запитів до сторонніх сайтів під час показу головної.
