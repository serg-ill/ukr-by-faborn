# 0.1.0-beta.2 — 2026-09-30

- Виправлено нескінченне зберігання індексу в пам’яті: кеш до однієї хвилини та повторне читання Pages перед кожним ручним запуском.
- Оновлено адреси потоків після підтвердженого HTTP 404 для старих сегментів «Бджоляра». Розклад Actions скорочено з 6 годин до 30 хвилин; затримки виконання GitHub можливі.
- Додано скасування запиту до запуску; застаріла відповідь після натискання «Назад» не вмикає відео.
- Помилка AVPlay під час старту показується з текстом; за відсутності завантаження відео протягом 45 секунд запуск закривається з меню повтору/якості.
- Таймер не закриває вже підготовлене відео, вибір продовження або плеєр іншого розширення.
- Повідомлення пошуку показує назву відкритої картки, меню — версію розширення.
- Покриття залишається обмеженим трьома назвами. Відтворення beta.2 на фізичному Samsung потребує перевірки; CORS браузерного плеєра залишається обмеженням.

# 0.1.0-beta.1

- Власна SVG-іконка та назва `ukr by Faborn` у картці Lampa, включно з видимим рядом кнопок нового інтерфейсу.
- GitHub Pages: один JS-файл та статичний JSON-індекс. GitHub Actions: оновлення відомих посилань Ashdi без стороннього API чи проксі.
- Пошук за українською/оригінальною назвою в обмеженому індексі.
- Два 4K-фільми; «Річер», сезон 3, 8 серій × 2 озвучення.
- Вибір джерела, озвучення, сезону, серії та фактичної якості.
- Плейлист, субтитри, стабільні ключі Lampa Timeline, остання серія та налаштування якості.
- Перевірка HLS перед початком перегляду, діагностика, збереження ознак застарілих даних.
- Виявлено CORS-обмеження на відеосегментах: вебплеєр Lampa не відтворює їх із зовнішньої адреси. Додано повідомлення та вимогу вибору Tizen / AVPlay для випробування на телевізорі.
- Межа beta.1: три назви, не повний пошук сайтів; без обходу захисних перевірок; фізичний Tizen ще не тестувався.
