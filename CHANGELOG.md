# 0.1.0-beta.6 — 2026-09-30

- Переклади згруповані для обраної якості: однакові назви не повторюються для кожного джерела.
- Перемикач якості зверху, збереження вибору й перехід до доступної якості, якщо обраної немає.
- Одне джерело запускається відразу; кілька джерел відкриваються всередині перекладу.
- «Назад» повертає до обраного перекладу, потім до картки. Групування не повторює мережевий пошук.
- Парсери джерел і передача потоку в Tizen / AVPlay збережені.

# 0.1.0-beta.5 — 2026-09-30

- Один список джерел, озвучень і якостей без ручного пошуку та проміжного вибору назви.
- Автоматичний пошук UAKino, UASerials, UAFix із перевіркою назви, типу й року сторінки; KinoUkr з резервного індексу.
- HDVB UA та вкладені Playerjs JSON: сезони, серії, українські озвучення. UAFix: окремі сторінки епізодів і сезонів.
- Виправлено розбір фільмів у AJAX-списках UAKino: номер серії більше не обов'язковий для фільму.
- Відновлення контролера картки після закриття меню і перед запуском плеєра; скасування всіх паралельних запитів, захист від пізніх відповідей.
- Таймаути загального пошуку й перевірки серії; часткова відмова джерел не забирає робочі результати.
- Недоступні потоки виключаються зі списку; діагностика перенесена в налаштування. Постійне посилання збережене.
- Наступна серія обирається вручну: до плеєра не передаються неперевірені URL.

# 0.1.0-beta.4 — 2026-09-30

- Додано «Знайти на UAKino» у картці: пошук назви TMDB поза індексом, вибір результату, озвучення та фактичної якості HLS. Оригінальну назву можна вибрати без ручного введення.
- Сторінка і вибраний Ashdi-плеєр читаються з пристрою за запитом. Підтримано посилання серій із HTML та AJAX-списку UAKino; наступні серії в цьому режимі поки вибираються вручну.
- Прямий шлях не залежить від наявності назви в JSON. Старий індекс і його плейлист збережено.
- На кожному етапі діють таймаут і скасування; помилка містить етап, HTTP-код або повідомлення про недоступний статус. Cloudflare не видається за порожній пошук.
- Діагностика показує локальний журнал і відкривається без очікування індексу. Виправлення налаштувань та захист запуску з beta.3 збережені.
- Користувач підтвердив відтворення попередньої beta.3. Прямий доступ beta.4 на фізичному телевізорі ще перевіряється; браузерна CORS-помилка оброблена у справжньому UI Lampa.

# 0.1.0-beta.3 — 2026-09-30

- Виправлено падіння під час відкриття налаштувань: поле адреси GitHub Pages тепер передає `values: ''`, обов’язкове для текстового поля Lampa. Помилку відтворено на справжньому ядрі з тим самим рядком стека, що на телевізорі.
- Пункт «Версія та діагностика» додано до меню модуля в картці. Діагностика показує доступність AVPlay API й останню спробу запуску.
- Нативну помилку початкового запуску перехоплено також з об’єкта відео: Tizen передає `event.error`, яке загальний обробник Lampa може не передати далі.
- Інструкція оновлення використовує постійне посилання. Редагувати URL на телевізорі не потрібно.
- Відтворення відео на фізичному Samsung поки не підтверджене; це виправлення налаштувань та діагностики.

# 0.1.0-beta.2 — 2026-09-30

- Виправлено нескінченне зберігання індексу в пам’яті: кеш до однієї хвилини та повторне читання Pages перед кожним ручним запуском.
- Оновлено адреси потоків після підтвердженого HTTP 404 для старих сегментів «Бджоляра». Розклад Actions скорочено з 6 годин до 30 хвилин; затримки виконання GitHub можливі.
- Додано скасування запиту до запуску; застаріла відповідь після натискання «Назад» не вмикає відео.
- Помилка AVPlay під час старту показується з текстом; за відсутності завантаження відео протягом 45 секунд запуск закривається з меню повтору/якості.
- Таймер не закриває вже підготовлене відео, вибір продовження або плеєр іншого розширення.
- Повідомлення пошуку показує назву відкритої картки, меню — версію розширення.
- Покриття залишається обмеженим трьома назвами. Відтворення beta.2 на фізичному Samsung потребує перевірки; CORS браузерного плеєра залишається обмеженням.

# 0.1.0-beta.1

- Власна SVG-іконка та назва `ukr by Faborn` у картці Lampa, включно з видимим рядом кнопок нового інтерфейсу.

- Плейлист, субтитри, стабільні ключі Lampa Timeline, остання серія та налаштування якості.
- Перевірка HLS перед початком перегляду, діагностика, збереження ознак застарілих даних.
- Виявлено CORS-обмеження на відеосегментах: вебплеєр Lampa не відтворює їх із зовнішньої адреси. Додано повідомлення та вимогу вибору Tizen / AVPlay для випробування на телевізорі.
- Межа beta.1: три назви, не повний пошук сайтів; без обходу захисних перевірок; фізичний Tizen ще не тестувався.
