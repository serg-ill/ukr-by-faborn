# ukr by Faborn — 0.1.0-beta.4

Розширення Lampa для Samsung Tizen: власна іконка у картці TMDB, українське озвучення й відтворення HLS через штатний Tizen / AVPlay. Код та резервний індекс розміщені на GitHub Pages. Окремий сервер не потрібен.

## Оновлення

Залиш установлене посилання й повністю перезапусти Lampa:

```text
https://serg-ill.github.io/ukr-by-faborn/ukr-by-faborn.js
```

У меню або «Версія та діагностика» має бути **0.1.0-beta.4**. Повторно вводити адресу, змінювати старий параметр `?v=…` чи додавати другу копію не потрібно. Якщо номер старий, Lampa могла залишитися у фоні або завантажити кеш після помилки мережі.

## Новий прямий пошук UAKino

1. Відкрий картку фільму або серіалу в каталозі TMDB.
2. Натисни **ukr by Faborn → Знайти на UAKino**.
3. Вибери відповідну назву у результатах. Рік і сезон допомагають відрізнити однойменні записи. Є пошук за оригінальною назвою з картки, редагування запиту та сторінки результатів.
4. Вибери озвучення, сезон/серію та якість. Якість береться з HLS-маніфесту; 4K з'являється лише за наявності відповідного варіанта.

Пошук бере назву з картки, а не TMDB ID: сайт не гарантує однакові ідентифікатори. Модуль не запускає перший приблизний збіг автоматично. Знайдену сторінку та обрану серію він читає безпосередньо з телевізора. Посилання Ashdi отримується при виборі відео; після хвилини або помилки запуску воно читається знову. Нової назви не має бути в `config/sources.json`.

Підтримано сторінки з відкритим Ashdi `/vod/…`, вбудовані списки епізодів та публічний AJAX-список UAKino. Українську мову підтверджує опис озвучення або `inLanguage=uk` сторінки. Інші плеєри та закодовані/вкладені конфігурації Ashdi ця бета поки не розбирає.

**У прямому пошуку beta.4 наступну серію треба обирати вручну.** Посилання розбирається тільки для вибраної серії; невідомі або старі URL не додаються до автоплейлиста. Інші сезони доступні у результатах пошуку та, якщо сторінка їх містить, у пункті «Інші сезони на UAKino».

Підтвердження на телевізорі: користувач повідомив, що попередня beta.3 вже відтворює відео. **Новий прямий пошук beta.4 ще потребує перевірки на цьому Samsung.** Звичайний браузер може відкрити сайт як сторінку, але заборонити читання його HTML через CORS. Установлений застосунок Tizen має інше оточення; попередній успіх AVPlay сам по собі не підтверджує доступу до HTML сайтів.

## Помилки й діагностика

Кожен мережевий етап має таймаут 18 секунд і скасовується кнопкою «Назад». Помилка показує етап: пошук, сторінка, список серій, Ashdi або HLS. Cloudflare/HTTP 403 не видається за відсутність фільму. `Мережа / CORS / TLS: HTTP-статус недоступний` означає, що середовище не надало HTTP-відповідь; це не точний діагноз одного з цих обмежень.

«Версія та діагностика» відкривається без мережевого запиту. У ній є версія, плеєр, AVPlay, останні етапи прямого пошуку та остання помилка запуску. Журнал зберігається локально в Lampa, не надсилається на GitHub. Для звіту достатньо фото екрана з помилкою або діагностикою.

Відео запускається через Tizen / AVPlay. Якщо воно не підготувалося за 45 секунд, модуль пропонує повтор, іншу якість або озвучення. Потоки Ashdi мають CORS-обмеження для браузерного відеоплеєра. Глобальні налаштування плеєра модуль не змінює.

## Резервний індекс

Старий перевірений шлях залишається у меню. Він містить 3 назви / 18 записів:

| Назва | Джерело | Озвучення / обсяг |
|---|---|---|
| Бджоляр (2024) | UAKino | Український дубляж, до 4K |
| Профі (2025) | KinoUkr | Український дубляж, до 4K |
| Джек Річер | UAKino | Сезон 3, серії 1–8, DniproFilm та Uaflix |

Автоплейлист послідовних серій зберігається для цього індексу. GitHub Actions оновлює відомі потоки кожні 30 хвилин, після push і за ручним запуском; можливі затримки GitHub. Кнопка «Оновити індекс із GitHub» читає готовий JSON, не запускає Actions. KinoUkr у beta.4 залишається джерелом індексу; прямий пошук додано для UAKino.

## Розміщення й перевірки

```text
GitHub Pages → код розширення → Lampa
Lampa → пошук UAKino → обрана сторінка → Ashdi → HLS → Tizen / AVPlay
GitHub Actions → оновлення резервного індексу → GitHub Pages
```

Стороннього API, проксі, VPS чи TorrServer немає. Відео не зберігається на GitHub. HTML сайтів не вставляється у Lampa, код сайтів не виконується. Запити обмежені UAKino та Ashdi. Перевірки доступу не обходяться.

Для власного репозиторію завантаж вміст пакета разом із `.github/`, увімкни **Settings → Pages → Source → GitHub Actions**, дочекайся build/deploy. Головна сторінка Pages покаже правильне посилання для встановлення. Для відкату можна повернути файли попереднього релізу й повторно опублікувати Pages.

Python 3.10+ та Node.js 20+, без додаткових pip/npm залежностей:

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/test_plugin.js
node --check ukr-by-faborn.js
python3 scripts/validate.py
```

Докази й межі перевірки — `VALIDATION.md`, контрольні суми — `SHA256SUMS.txt`. JSON на Pages оновлюється workflow та може відрізнятися від знімка в ZIP.

Технічні джерела: [Lampa Player API](https://github.com/yumata/lampa-source/blob/main/src/interaction/player.js), [Tizen AVPlay](https://github.com/yumata/lampa-source/blob/main/src/interaction/player/video/tizen.js), [публічний формат UAKino playlist](https://github.com/Nightmare84/repository.nightmare/blob/HEAD/matrix/plugin.video.uakino.club/site_parser.py), [репозиторій та Actions](https://github.com/serg-ill/ukr-by-faborn/actions).
