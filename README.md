# ukr by Faborn — 0.1.0-beta.48

Розширення Lampa для Samsung Tizen. Код і резервний індекс розміщені на GitHub Pages. Основні джерела працюють без окремого сервера; нова, вимкнена за замовчуванням бета UAKinogo використовує Ubuntu лише для отримання посилань. Відео відтворюється через Tizen / AVPlay; окремий браузерний механізм можна ввімкнути в налаштуваннях Faborn.

## F Fold, локальні запити й паролі — beta.48

Новий знак **F Fold** у кнопці онлайну, налаштуваннях, вікнах джерел і серій, на сторінці встановлення та в адмінпанелі. Кнопка залишається без підпису; логотип — легкий SVG зі статичним блакитно-фіолетовим градієнтом.

В адмінпанелі: **Домашня мережа** в огляді й списку користувачів, статистика локальних IP з логіном і без нього та фільтр **Лише локальні** у журналі. **Мій пароль** змінює пароль адміністратора після перевірки поточного; при створенні користувача або зміні його пароля можна задати власний чи згенерувати випадковий. [Оновлення сервера й інструкція](server/uakinogo/ADMIN.md).

Для логотипа перезапустіть Lampa. Для доповнень панелі оновіть Ubuntu до **beta.48**: порт, користувачі, статистика та правила доступу зберігаються. Відео й далі надходить прямо на телевізор; лічильники показують трафік JSON API обробника.

## Адмінпанель сервера — beta.47

На домашньому Ubuntu тепер доступна окрема мініпанель: запити, API-трафік, помилки, логіни, останній IP і активність. Створення користувача, випадковий пароль, копіювання посилання для Lampa, блокування та відновлення доступу — у браузері. [Встановлення й керування панеллю](server/uakinogo/ADMIN.md).

Для цієї функції **оновіть обробник Ubuntu** та ввімкніть `--admin-lan 192.168.88.0/24`. Адмінпанель має окремий пароль; звичайні логіни й локальний доступ без пароля не надають прав адміністратора. Порт, користувачі й конфігурація перегляду зберігаються. Відео й далі надходить на телевізор напряму; лічильники панелі охоплюють JSON API обробника.

## Мова озвучення та найкраща якість — beta.46

Над якістю додано рядок **Українська · English · Російська · Усі мови**. Типова мова — українська. Режим **Найкраща** показує кожне озвучення на його максимальній доступній якості: українські 1080p не зникають через англійські 4K або інший український реліз у 4K. Джерела одного озвучення згруповані; поруч із кожним видно його фактичну якість. Кнопка «Дивитися» запускає найякісніше джерело вибраного озвучення, пріоритет сайту застосовується при однаковій якості.

Мову можна змінити одразу у вікні перегляду; додаткового пошуку немає. Зміна мови вмикає **Найкраща**, ручний вибір 4K / 1080p / 720p та інших наявних якостей залишається доступним. Обрані мова й режим якості зберігаються; попереднє ручне налаштування якості не скидається під час оновлення. Якщо обраної мови немає, з’являється повідомлення та кнопка **Показати всі мови**, без автоматичного переходу на іншу доріжку. Невідомий «Оригінал» не видається за English.

Працює в **Панелі**, **Кінозалі** та **Стандартному Lampa**. Налаштування: **ukr by Faborn → Перегляд і джерела → Мова озвучення / Бажана якість**. Режим «Найкраща» зберігається після запуску, наступної серії та повернення з обох плеєрів. Якщо мову змінили в плеєрі, повернення показує вибрану доріжку.

Повністю перезапустіть Lampa; адреса розширення та налаштування сервера залишаються ті самі. **Для цієї функції оновлювати Ubuntu не потрібно**: сервер beta.45 / beta.45.1 сумісний, відеотрафік через нього не передається. Серверний архів beta.46 змінює лише номер версії та посилання інсталятора.

## Локальний сервер без тестового логіна — beta.45.1

Порожній логін показує **Не задано**, без підставленого `test1`. У **UAKinogo · сервер** додано **Очистити логін і пароль**: адреса та інші налаштування зберігаються. Редактор логіна відкриває фактично збережене значення, дозволяє порожнє й не записує введене в історію клавіатури.

Сервер із увімкненою авторизацією раніше вимагав пароль і в домашній мережі. Для доступу вдома без пароля оновіть Ubuntu із `--allow-lan 192.168.88.0/24`, потім очистіть логін і пароль у Lampa та залиште адресу `http://192.168.88.191:8789`. Потрібне саме оновлення сервера: перезапуск Lampa не змінює його правила доступу. Зовнішні клієнти продовжують входити зі своїми обліковими даними.

```sh
curl -fL https://raw.githubusercontent.com/serg-ill/ukr-by-faborn/v0.1.0-beta.45.1/server/uakinogo/install.sh -o /tmp/faborn-install.sh &&
sudo bash /tmp/faborn-install.sh --port 8789 --allow-lan 192.168.88.0/24
```

Виняток для локальної мережі типово вимкнений; перевіряється справжня TCP-адреса клієнта, а не HTTP-заголовки. Порт і користувачі зберігаються. Повторний запуск із `--allow-lan none` прибирає виняток. [Подробиці доступу](server/uakinogo/ACCOUNTS.md).

## Плеєр, налаштування й авторизація — beta.45

Faborn Player отримав керування у стилі Lampa: повноширинний таймлайн, час і залишок, пауза по центру, перемотування ліворуч та якість / субтитри / озвучення праворуч. Підписи кнопок з’являються при фокусі пульта. Для теми iOS зберігається окрема прозорість плеєра. Використовується вже перевірений механізм браузерного HLS.

У налаштуваннях тепер 8 головних пунктів із короткими підрозділами; попередні значення збережені. Фон налаштувань iOS має статичне скляне оформлення без живого розмиття при навігації. На стенді справжнього ядра кількість елементів цього меню зменшилася приблизно утричі; відчуття швидкодії на фізичному Samsung треба перевірити окремо.

Сервер підтримує логін і пароль. Поле **UAKinogo · сервер → Сервер UAKinogo** приймає також `user:password@server:port` й відділяє облікові дані від адреси. Пароль не показується в рядку налаштувань та не додається до історії клавіатури. HTTPS шифрує його під час передавання. Логін і пароль передаються тільки обробнику метаданих; відеотрафік не проходить через Ubuntu.

Для авторизації потрібно оновити Ubuntu-обробник. Інсталятор з `--test-users` створює **test1** і **test2** з різними випадковими паролями, які друкуються лише у приватному терміналі при першому створенні. Повторне встановлення зберігає користувачів. [Керування обліковими записами](server/uakinogo/ACCOUNTS.md) включає додавання, зміну пароля й видалення без перезапуску сервісу.

## Браузерний HLS — beta.44

Для **Плеєр онлайн → Faborn Player · бета** додано окремий параметр **Механізм бета-плеєра → Браузерний HLS · бета**. Типовий механізм — **Samsung AVPlay**. Новий режим використовує HTML5 `video` та MediaSource через HLS.js, як другий плеєр Alloha на сайті. Це інший шлях передавання потоку в браузерний декодер, без конвертації відео чи нового програмного декодера. Підтримка MediaSource і потрібного кодека має бути в самому застосунку телевізора.

HLS.js завантажується з GitHub Pages лише для запуску вибраної бети; звичайне меню й штатний плеєр його не завантажують. Окрема назва `FabornHls` зберігає наявний `Hls` інших розширень. Обмежені параметри буфера; при закритті знищуються HLS-сесія, слухачі й очікування перемотування. Збережено панель керування, якість, озвучення, позицію та зовнішні SRT/VTT субтитри; вибір внутрішніх доріжок субтитрів MSE у цій беті не доданий.

Для UAKinogo залишається чинний адаптер заголовків на телевізорі та обробник метаданих Ubuntu. Серверний API не змінений; перевстановлення Ubuntu не потрібне. Перевірка на Mac використовує окремий тестовий HTTP-канал, а не новий серверний медіапроксі продукту.

Діагностика запам'ятовує Alloha й вибрану якість до підготовки потоку, показує MSE / AVPlay, етап запуску та доступний HTTP-код. Повторне відкриття джерел зберігає результат попередньої локальної перевірки й трафіку; вони скидаються тільки при наступному запуску. `InvalidAccessError` сам по собі не доводить несумісність кодека.

На стенді зі справжнім ядром Lampa та справжнім медіа Alloha перевірено UA / EN **3840×2160**, рух часу й декодовані кадри, 4K ↔ 1080p зі збереженням позиції, перемотування на паузі та Back до кешованих джерел. HTTP 403 змодельовано окремо; після помилки керування повертається до джерел. Під час пізнішого повтору CDN відмовив HTTP 403 для свіжих 4K і 1080p адрес: доступність посилання може змінюватися незалежно від декодера. Back після цієї справжньої відмови також повернув джерела. Samsung worker / локальний канал у цьому браузерному тесті — тестова заміна. Після beta.44 користувач підтвердив запуск браузерного HLS на своєму Samsung. Оновлене керування beta.45 і відтворення на інших телевізорах ще потребують перевірки.

Бібліотека: [HLS.js 1.7.3](https://github.com/video-dev/hls.js/releases/tag/v1.7.3), Apache-2.0. Походження та зміна експорту описані в [lib/hls/README.md](lib/hls/README.md), ліцензія включена в [lib/hls/LICENSE](lib/hls/LICENSE).

## Галочка, клавіатура та запуск UAKinogo — beta.42

Штатна позначка «Перегля…» у повній картці тепер показується зеленою галочкою справа вгорі постера, як у списках. Назва статусу збережена для доступності. Для iOS-клавіатури прибрано розмиття й анімації під час переходу між літерами; збережені кольори фокуса. Кеш прогресу зберігається при звичайній навігації й оновлюється після зміни переглянутого або таймлайна, без повторного сканування всіх серій при кожному оновленні постерів.

UAKinogo перевіряє ініціалізаційний файл відео та відповідь локального HLS-каналу до запуску AVPlay. Недоступний канал завершує перевірку з повідомленням, без відкриття плеєра. Після помилки AVPlay закривається після повернення з native callback; локальний канал зупиняється після закриття плеєра. «Назад», запізнілі відповіді та повторний запуск перевірені у справжньому ядрі Lampa з імітацією AVPlay. Опитування локального каналу під час перегляду обмежено 25 разами за секунду; у звичайному меню воно не запускається.

**Повністю перезапустіть Lampa та перевірте 0.1.0-beta.45 у «Версія та діагностика».** Там додані рядки **«UAKinogo · локальна перевірка»** й **«UAKinogo · локальний канал»**: HTTP-стан, кількість з’єднань, відповідей, відхилених запитів та переданих даних. Підписані URL й токени не зберігаються. **Обробники Ubuntu beta.40 / beta.41 сумісні, переустановлення не потрібне.** Адреса сервера й порт залишаються тими самими.

Фото `code [15] PLAYER_ERROR_CONNECTION_FAILED` означає збій підключення AVPlay до вмісту; конкретна причина на фізичному Samsung ще не встановлена. 564 автоматичні перевірки та контрольний запуск на стенді пройшли. Передавання й декодування 4K UAKinogo на телевізорі ще потрібно перевірити після оновлення.

## Виправлення UAKinogo та три студії — beta.41

Виправлено **HTTP 413**: запит до Ubuntu містить лише назви, дату, мову й тип відкритої картки, а не весь об’єкт TMDB з описом та акторським складом. Це діє під час пошуку, зміни серії й оновлення посилання перед запуском. Помилки обробника показують конкретну причину; 413 більше не подається як відсутність назви.

**Достатньо повністю перезапустити Lampa та перевірити версію 0.1.0-beta.41 у діагностиці. Установлений обробник Ubuntu beta.40 сумісний; для цієї правки переустановлення не потрібне.** Адресу сервера й вибраний порт збережіть. Новий серверний пакет beta.41 має той самий API та ліміт запиту 16 KiB.

У верхньому рядку картки — максимум **три студії**, без «+N» та без переносу. Повний список залишається у штатних деталях Lampa. У документації виправлено відновлення systemd після повідомлення `Unit faborn-resolver.service not loaded`.

## KinoBase та серверна бета UAKinogo — beta.40

KinoBase більше не втрачає пізню відповідь через початковий ліміт пошуку: після показу перших результатів перевірка триває до 60 секунд, нові озвучення й 4K доповнюють відкритий список. «Назад», запуск відео або інша картка скасовують старі запити; пізня відповідь не перехоплює відкрите меню якості чи серій.

**Налаштування → ukr by Faborn → Сервер UAKinogo**, потім **UAKinogo · серверна бета → Увімкнено**. [Інсталяція Ubuntu з Mac](server/uakinogo/README.md). Перша бета без ключа; старий прапорець Alloha її не вмикає. Ubuntu обробляє сторінки та API плеєра, відео завантажується самим телевізором. На телевізорі працює локальний адаптер заголовків потоку; потрібен Tizen 5.5+ із Tizen Sockets / WebAssembly та сумісним AVPlay. UAKinogo у цій бета-версії використовує штатний плеєр Lampa з Tizen / AVPlay. Перегляд на фізичному Samsung ще не підтверджено.

HTTP-перевірка: «Оппенгеймер» і «Унабомбер» віддали **3840×2160, AV1 + AAC**, UA / EN / RU; «Друзі» — до 1080p, 234 серії. Це не перетворення AV1 на підтримуваний старим телевізором кодек. У першій бета UAKinogo наступна серія вибирається вручну; прогрес, «З початку», зміна озвучення й повернення до знайдених джерел збережені. Автоперехід звичайних джерел не змінений.

## Студії та швидкодія

У картці показуються перші три доступні студії окремими кольоровими бейджами: без лічильника «+N» і без переносу. Дата релізу, віковий рейтинг і статус залишаються в тому самому рядку; довгі назви компактно скорочуються всередині бейджа.

Прибрані зайві перебудови бейджів під час навігації й повторні оновлення картки від зміни фокуса. Прогрес оновлює видимі постери одним пакетом; обробники закритої картки відключаються. Швидкодія перевірена за кількістю операцій у справжньому ядрі Lampa; результат на фізичному Samsung потрібно оцінити після оновлення.

## Faborn Player · бета — beta.38

**Налаштування → ukr by Faborn → Плеєр онлайн → Faborn Player · бета.** Типовий вибір — **Lampa**. Вибір зберігається й застосовується до наступного запуску онлайн-джерела Faborn. Бета використовує Samsung AVPlay без штатного контролера відтворення Lampa; потрібен застосунок Tizen із доступним `webapis.avplay`. Якщо API недоступний, показується повідомлення й повернення до джерел. Торренти та сторонні розширення використовують свої плеєри.

Власна панель містить паузу, перемотування, вибір якості та озвучення, доступні вбудовані / SRT / WebVTT субтитри, «З початку», наступну серію та повернення до джерел. Якість і озвучення перемикаються зі збереженням позиції; перед перемиканням або наступною серією оновлюється посилання. Автоперехід враховує штатний перемикач Lampa «Наступна серія», працює в межах доступної безперервної черги сезону. Прогрес спільний зі звичайним запуском і торрентами; фільми після 80% додаються до переглянутих. Назад повертає до вже знайдених джерел. Пульт: вліво / вправо на шкалі — перемотування, вниз — кнопки, OK — вибір; Назад спочатку закриває меню доріжок, потім плеєр.

Панель враховує тему й окрему **«Прозорість плеєра iOS»**. Після помилки доступні повтор, інша якість і вихід; мережевий збій допускає до трьох адрес тієї самої якості, без автоматичного переходу з 4K на 1080p. У діагностиці є обраний плеєр, етап запуску, стан AVPlay та код помилки без підписаних URL. Код бети завантажується з GitHub Pages лише при першому запуску, власний сервер не потрібен.

Це інший спосіб керування штатним AVPlay, а не новий відеодекодер. Механізм пропуску вступу / титрів у цій першій беті ще не підключений; він залишається у звичайному запуску Lampa. Відтворення проблемного 4K на фізичному Tizen 3 не підтверджено — локальна перевірка використовує справжнє ядро Lampa та імітацію API телевізора.

## 4K на старому Tizen — beta.37

**Налаштування → ukr by Faborn → 4K на старому Tizen → Увімкнено · тест сумісності.** Після ввімкнення повторно відкрий відео KinoBase у 2160p. Початково режим вимкнений; застосовується лише до вбудованого плеєра Tizen / AVPlay на UHD-телевізорах із Tizen 2.3–4.x. Відтворення 1080p та Tizen 5 / 6.5 і новіші не змінює.

Перед підготовкою саме цього потоку режим явно вмикає UHD-декодер через штатний `SET_MODE_4K`. Зберігає якість, озвучення, прогрес і повтор на запасній адресі; при недоступному API продовжує звичайний запуск. У «Версія та діагностика» є рядок **«4K старого Tizen»** із результатом. Це тест сумісності: він не перекодовує відео й не виправляє його H.264-профіль. Відтворення проблемного 4K «Унабомбера» на фізичному Tizen 3 ще має перевірити користувач. [Документація Samsung AVPlay](https://developer.samsung.com/smarttv/develop/api-references/samsung-product-api-references/avplay-api.html).

## Каталог фільмів, переглянуте й діагностика — beta.37

На переглянутих постерах справа вгорі показується **зелена галочка**. Вона враховує «Переглянуто» Lampa та медіатеку Faborn поточного профілю, зокрема автоматичне додавання фільму після 80% перегляду. Піктограма є в каталозі, на головній і в медіатеці, працює також зі стандартними постерами. Зміна групи відразу оновлює відмітку; у серіалів поруч залишається номер останнього переглянутого епізоду, якщо він відомий.

У загальному меню **«Фільми»** TMDB над постерами доступні популярність / рейтинг / новинки, мінімальна кількість оцінок і країна. Типово — **популярні, 100+ оцінок, усі країни**. Фільтри застосовуються до запиту перед пагінацією; вибір фільмів і серіалів зберігається незалежно. **Налаштування → ukr by Faborn → Каталог фільмів → Звичайна Lampa** повертає штатний каталог. Логотипи Dolby в бейджах відцентровані візуально.

У «Версія та діагностика» додано модель Samsung, версію Tizen, доступність UHD та стан AVPlay останнього запуску. Для KinoBase відображаються відомі параметри отриманого маніфесту: роздільність, кодеки, кадри за секунду, бітрейт і канали аудіо. Невідомі дані не вгадуються; нові запити й підписані посилання не додаються. Старі помилки та чужа черга серіалу очищуються при новому запуску. Це допомагає дослідити 4K на старих телевізорах, але не є підтвердженим виправленням декодування на Tizen 3.

Перезавантаження потребує вибору у вікні підтвердження, не очищує налаштування й історію та недоступне під час відео. **ukr by Faborn** стоїть першим у загальному списку налаштувань. Нові іконки підтримують iOS, Faborn і стандартну тему.

## Сортування серіалів та виправлення — beta.36

Загальне меню **«Серіали»** для TMDB відкриває каталог із фільтрами над постерами. Типово: **популярні, щонайменше 100 оцінок, усі країни, серіали й мінісеріали**. Можна вибрати рейтинг або новинки, поріг 0 / 20 / 50 / 100 / 500 / 1000 оцінок, країну та всі типи телепроєктів. Фільтри зберігаються й застосовуються до запиту TMDB перед розбиттям на сторінки; каталог використовує штатні постери, навігацію та дозавантаження Lampa. Пошук конкретної назви залишається доступним незалежно від фільтрів. **Налаштування → ukr by Faborn → Каталог серіалів → Звичайна Lampa** повертає штатний розділ.

«Моя медіатека» скорочено до **«Медіатека»**; збережені списки та прогрес не змінюються. В iOS кнопка паузи має форму інших кнопок теми, літери екранної клавіатури відцентровані. KinoBase показує компактні назви перекладачів; епізод без назви доріжки більше не успадковує довгий перелік озвучень усього серіалу. Відсутність збігу назви й року відображається окремо від помилки доступу до джерела.

## Компактна картка, плеєр iOS та запасні адреси KinoBase — beta.35

Рейтинги й усі реакції зібрані в один компактний ряд. Нижче — якість онлайну й торрентів, потім **дата → студії → вік → статус**. Вміст не прибрано; кнопки зберігають розмір, довгі ряди переносяться. Нативні реакції та рейтинги продовжують оновлюватися. Підтримуються Faborn, iOS і стандартна Lampa.

Плеєр у темі **iOS · Liquid Glass** отримав темні напівпрозорі панелі з відступами від країв, компактну інформацію про відео, окремі кнопки й акцентний прогрес. **Налаштування → ukr by Faborn → Прозорість плеєра iOS**: непрозоре, низька, стандартна, висока або максимальна. Це окреме збережене налаштування, незалежне від «Прозорість скла iOS» для меню; зміни діють одразу. Відеошар Tizen не розмивається, штатні кнопки та керування пультом збережені.

Якщо AVPlay не підключився до потоку KinoBase, Faborn автоматично пробує запасні адреси, які саме джерело віддало **для тієї ж серії, озвучення й якості**. Максимум три різні адреси разом із початковою; час зупинки та плейлист зберігаються. За вичерпаних адрес залишається вибір оновлення посилання, іншої якості чи джерела. Рядок **«Потік KinoBase»** у діагностиці показує сервери та результат без підписаних URL. Це відновлення після помилки підключення на старті, а не гарантія доступності CDN в кожній мережі.

Оформлення підтримує Faborn, iOS та стандартну Lampa; додаткових запитів метаданих немає.

## Медіатека та керування коментарями — beta.33

**«Медіатека»** замінює пункт «Мої серіали» у боковому меню. Угорі дві вкладки: **«Фільми» / «Серіали»**. Усі збережені серіали, відмітки, прогрес і сповіщення залишаються; вибрана вкладка відновлюється після перезапуску.

Для фільмів є групи **«Хочу подивитися»** та **«Переглянуто»**. Фільми, які хочеш подивитися, завжди стоять першими у фільтрі «Усі»; кожну групу можна відкрити окремо. Натисни іконку медіатеки в картці фільму та вибери групу. Додавати також можна з пошуку або історії; **довге OK** на фільмі в медіатеці відкриває зміну групи та видалення зі списку. Видалення не стирає час зупинки чи історію Lampa.

Коли прогрес фільму досягає **80%**, він автоматично додається до **«Переглянуто»**, навіть якщо його не було в медіатеці. Наявний фільм із «Хочу подивитися» переходить у «Переглянуто» без дубля. Потрібні картка фільму й події прогресу від плеєра Lampa або Timeline: це підтримує онлайн і штатний запуск торрентів. Серії, трейлери та відео без достовірної прив’язки до фільму не додаються. Правило діє під час подальшого перегляду; стару історію можна додати вручну. Списки локальні, окремі для кожного профілю, до 500 фільмів і 120 серіалів. **«Переглянуте та перенесення»** у налаштуваннях копіює також відсутні фільми з іншого збереженого профілю на цьому пристрої; поточні групи й прогрес не перезаписуються.

**Налаштування → ukr by Faborn → Коментарі в картці:** **«Лише з джерел»**, **«Лише Lampa»**, **«Усі»** або **«Приховати всі»**. Початковий режим — лише джерела; якщо раніше їх явно вимкнули, зберігаються лише штатні коментарі. Після зміни повторно відкрий картку. Приховані блоки не залишають порожнього місця в навігації.

## Коментарі з джерел — beta.32

Faborn сам читає публічні відгуки зі сторінок **UAFix** та **UASerials**. У картці фільму / серіалу під описом з’являється окремий ряд **«Коментарі з джерел»**: автор, дата сайту, реакції, назва джерела та до чотирьох рядків тексту. **OK** — повний відгук, **Назад** — на той самий коментар. Позначені сайтом спойлери відкриваються лише після **«Показати спойлер»**; непозначені спойлери автоматично не визначаються.

Відповіді позначені окремо, джерела чергуються. Кеш у пам’яті до 4 годин і повторне використання вже знайдених сторінок зменшують кількість запитів. Помилки доступу / CORS / TLS показуються як недоступність сайту, а не як відсутність відгуків; окремого сервера або проксі не потрібно, доступ залежить від застосунку та мережі.

У beta.33 показ обох блоків регулює **Налаштування → ukr by Faborn → Коментарі в картці**. Після зміни повторно відкрий картку. Режим «Усі» залишає штатні коментарі CUB окремим рядом. Інтеграція призначена для читання: публікувати відгуки чи ставити реакції на сайтах вона не може. Підтримуються поточні збірки Lampa з API Maker; в старих збірках без нього ряд не додається.

## Переглянуте та перенесення — beta.29

У **«Моїх серіалах» → «Переглянуте»** можна позначити весь серіал станом на сьогодні, окремий сезон або всі епізоди до обраного включно. Дія також доступна в меню іконки **«✓»** у картці та довгим натисканням **«+» / «✓»** або серіалу в центрі. Перед збереженням показується кількість епізодів. Дати перевіряються за TMDB: майбутні, недатовані серії й спецвипуски не позначаються. Якщо отримати дані сезону не вдалося, відмітки не змінюються.

Відмітки потрапляють до штатного Timeline Lampa й спільних ключів Faborn: їх бачать серії, постери та прогрес онлайну / торрента. Для поточного завершеного сезону й переглянутої останньої випущеної серії незавершеного серіалу показується **«Очікуємо нових серій»**; такий серіал залишається у фільтрі **«Очікуються»**, навіть якщо наступна дата ще невідома. Новий епізод надалі залишиться непроглянутим. У **«Переглянуте» → «Скасувати останні відмітки»** доступне відновлення попереднього прогресу; подальший перегляд або новіші зміни не перезаписуються. Скасування стосується прогресу, а не видалення серіалів зі списку.

**Після зміни акаунту:** Lampa використовує окремий Timeline кожного профілю; Faborn теж зберігає окремі списки. У **«Переглянуте» → «Перенести з іншого профілю»** можна явно скопіювати збережені на цьому пристрої відмітки й список Faborn. Джерело залишається без змін; у поточному профілі заповнюються лише відсутні записи, збережені скидання й поточний прогрес захищені. Показується кількість записів прогресу та серіалів (записи можуть містити кілька ключів одного епізоду).

Ті самі дії доступні через **Налаштування → ukr by Faborn → Переглянуте та перенесення**. Це локальне копіювання, не новий сервіс синхронізації: якщо кеш старого профілю видалений, був на іншому пристрої або не завантажувався сюди, його неможливо відновити цим способом. У такому разі використовуй швидке позначення сезонів.

## Повторний перегляд і нові серії — beta.28

**Швидкий повторний перегляд:** відкрий панель плеєра й вибери кругову стрілку **«З початку · 00:00»** поруч із Play / Pause. У вікні джерел Faborn також є **«З початку»**, коли збережений прогрес, навіть якщо фільм уже завершений. Дія працює в Панелі, Кінозалі й стандартному списку Lampa; скидає лише поточний фільм або серію. Спільна позиція онлайну / торрента змінюється після фактичного переходу плеєра до початку. Якщо запуск не вдався, попередня позиція зберігається. Штатне налаштування продовження перегляду не змінюється.

**Дата нової серії:** у картці серіалу та у вкладці «Мої серіали» з’являється компактний бейдж **«Нова серія сьогодні / завтра / через 3 дні»** з номером сезону, серії та датою. Після недавнього виходу може показуватися «Вийшла нова серія». Якщо TMDB не має дати, відліку немає.

**Сповіщення:** натисни «+» у картці серіалу, щоб стежити за ним. Перша перевірка запам’ятовує поточний стан; про наступний новий епізод модуль повідомить один раз у меню Lampa. Перевірка виконується раз на 6 годин, поки застосунок працює; повідомлення чекає закриття відео та списку вибору. Вже переглянуті епізоди не спричиняють повідомлення. Список і стан сповіщень окремі для кожного профілю. При вимкненому телевізорі або закритій Lampa сповіщення не надсилаються.

**Налаштування → ukr by Faborn → «Відлік до нової серії» / «Сповіщення про нові серії»**: два незалежні перемикачі, початково ввімкнені. Дати беруться з TMDB: це дата виходу епізоду, а не підтвердження доступності потоку чи українського озвучення. Додатковий сервер не потрібен.

## Мітки джерел і компактний хедер — beta.24

**Налаштування → ukr by Faborn → Пропуск за мітками джерела.** Окремий перемикач, початково вимкнений. Модуль читає явні інтервали `skip` з відкритої конфігурації PlayerJS у вже підтримуваних джерелах Ashdi / HDVB та з окремих елементів плейлиста KinoBase. Новий адаптер HDRezka не додається. [Формат міток PlayerJS](https://playerjs.com/docs/en=skipbutton).

Якщо джерело не позначає тип відрізка, кнопка має назву **«Пропустити фрагмент»**. Вона з’являється лише в межах його мітки: відлік **7 секунд**, **OK** — пропустити зараз, **Назад** — скасувати без виходу з відео. Пропуск веде точно до кінця позначеного фрагмента; його тип не вгадується й серія не позначається завершеною лише через таку мітку.

Придатні мітки джерела мають пріоритет. Якщо їх немає або вони не відповідають тривалості відео, залишається IntroDB за ввімкненими налаштуваннями вступу / титрів. Вмикання лише нового перемикача не вмикає IntroDB. Мітки двох джерел не змішуються для одного відео. Мітки папки чи сезону не поширюються на всі серії; після зміни серії, озвучення або якості беруться дані вибраного потоку, а попередні очищаються.

Жива перевірка двох сторінок Ashdi не знайшла таких міток: нова підтримка **не гарантує пропуск у кожному відео**. Перевірено парсинг, передачу до плеєра, відлік, скасування, наступну серію та резерв IntroDB у справжньому ядрі Lampa з тестовими метаданими й імітацією AVPlay. Відтворення на фізичному Samsung ще не перевірене. Окремий сервер і відеопроксі не потрібні.

Хедер вікна джерел став компактнішим приблизно на **20%**. Градієнт більше не фарбує нижній роздільник і не обводить шапку рамкою; в iOS залишається власний скляний роздільник. Іконка й кнопка закриття зберігають розмір, довга назва не витісняє хрестик.

## Серії, повернення до джерел і пропуск за мітками — beta.23

Після завершення серії запускається наступна **в тому самому сезоні та озвученні**, якщо її віддало джерело й у Lampa увімкнено штатний автоперехід до наступної серії. Пропуски номерів і недоступні серії не перескакуються. Посилання наступної серії оновлюється й перевіряється перед запуском; зберігається вибрана якість або береться доступна нижча. Кнопки плейлиста у плеєрі теж працюють.

**Назад із плеєра** повертає до збереженого вікна джерел на поточній серії, без повторного пошуку сайтами. Фокус — на виборі серії; після вибору — одразу на «Дивитися». Працює в «Панелі», «Кінозалі» й стандартному вікні Lampa. Завершена серія записується як переглянута, наступна не отримує її завершений прогрес.

**Налаштування → ukr by Faborn → Пропуск вступу за мітками / Пропуск титрів за мітками.** Обидва перемикачі початково вимкнені. Коли ввімкнеш, на відповідній мітці з’явиться кнопка з відліком **7 секунд**: **OK** виконує дію одразу, **Назад** скасовує її й залишає відео відкритим. Сім секунд — час відліку кнопки, а не початок вступу чи довжина пропуску. Пауза, очікування відео й діалог продовження не витрачають відлік.

Мітки читаються з [IntroDB](https://introdb.app/docs/api) за точним IMDb ID фільму або серіалу, сезоном і серією; підписка, ключ і власний сервер не потрібні. Перевіряються межі відносно тривалості відео. Без відповідних міток кнопки немає й час не вгадується. Дані спільноти можуть відрізнятися для іншої монтажної версії; аналізу самого відео немає. Покриття не охоплює всі назви.

На кінцевих титрах наступна серія запускається за доступним плейлистом. Якщо зазначена сцена після титрів, пропуск веде до неї; завершення й автоперехід не спрацьовують завчасно. Для торрентів потрібна точна прив’язка до картки й конкретної серії. Якщо інше розширення вже передало штатні сегменти Lampa, їхнє керування зберігається без другого автоматичного пропуску.

Стан видно в **«Версія та діагностика → Вступ і титри»**. При недоступному API перегляд триває без пропуску. Для Samsung використовується прямий HTTPS-запит метаданих і резерв через вбудований адаптер Samsung, якщо доступний мережевий API застосунку. Сервер користувача й відеопроксі не потрібні. Браузер може блокувати API через CORS; фізичне відтворення на телевізорі потребує перевірки.

На телевізорі — **шість постерів у ряд**. Під ними одразу студії, нижче вже видно наступну добірку; зайві вертикальні проміжки прибрані. Картка, яка не вміщується під час гортання, стає першою на наступній сторінці. Один опис вибраної назви залишається над рядом; він не дублюється під кожним постером.

**Налаштування → ukr by Faborn → Бейджі на постерах:** «Скляні капсули», «Кіноплашки», «Мінімальні значки» або «Стандартні Lampa». Оформлення діє і на головній, і в категоріях. Якщо якість ще не перевіряли, модуль її не вигадує й не запускає масовий пошук джерел.

Дані беруться зі штатного прогресу поточного профілю, зокрема онлайну й торрента. **«Вийшов сезон 3»** з’являється за датою виходу й кількістю серій у TMDB; це інформація про вихід сезону, а не підтвердження доступності потоку. Метадані сезону уточнюються при фокусуванні постера.

Початкова кнопка картки — іконка Faborn; захист від пізнього перехоплення фокусу стороннім плагіном припиняється після руху пультом. **Налаштування → ukr by Faborn → Початкова кнопка в картці → ukr by Faborn / Вибір Lampa.** Обраний вручну порядок кнопок зберігається.

## Спільний прогрес онлайн ↔ торрент — beta.21

Час зупинки, прогресбар і **«Переглянуто»** спільні для тієї самої картки TMDB та конкретної серії. Після онлайн-перегляду торрент підхоплює позицію, а після торрента онлайн показує останню серію та час. Зберігається штатне налаштування плеєра Lampa: продовжити автоматично, запитати або почати заново.

У файлах торрента видно прогрес і **«Продовжити S1E2 · 8:30»** або **«Переглянуто»**. Для відкритих раніше роздач у списку також є прогресбар; сезонний пакет показує кількість завершених серій. Весь пакет позначається переглянутим лише після всіх його відомих серій. Поріг завершення — 90%, як у Lampa. Штатні ручні дії «переглянуто / скинути» у списку файлів синхронізуються з онлайн-прогресом.

Час записується кожні 15 секунд, додатково на паузі та звичайному виході. Раптове вимкнення живлення може втратити останні 15 секунд. Час і відмітки зберігаються через штатну історію поточного профілю Lampa. Модуль не додає окремого сервера синхронізації між телевізорами. Індекс роздач містить лише ідентифікатори й номери файлів, без посилань на потоки.

Для спільного прогресу серії потрібні надійно визначені сезон і номер. Невідомі серії, бонуси й багатосерійний файл не прив'язуються навмання. Вперше знайдена роздача отримує зв'язок із серіями після відкриття списку файлів. Різні монтажні версії або заставки можуть мати зміщення: переноситься час у секундах, без аналізу кадрів.

У діагностиці є стиль, кількість намальованих кадрів та остання помилка. [Джерела й ліцензії ефектів](ASSET_NOTICES.md).

## Рейтинги та дані релізів

Панель рейтингів зменшена приблизно на **37% заввишки**, зі збереженням іконок, назв сервісів і шкал. У beta.14 вона лише оформлювала дані, вже наявні в картці: без іншого постачальника оцінок часто залишалися тільки TMDB та «Оцінити».

Модуль отримує IMDb ID з TMDB, а за ним — **IMDb через [Cinemeta](https://v3-cinemeta.strem.io/manifest.json)** та доступні **Rotten Tomatoes / Metacritic через [Ratings Aggregator](https://rating-aggregator.elfhosted.com/)**. У beta.16 додано резерв через відкриті дані [Wikidata](https://www.wikidata.org/): спочатку точне зіставлення IMDb ID, потім оцінки з перевіркою сервісу, шкали, методу й дати. Оцінки глядачів не видаються за оцінки критиків, оцінка окремого сезону не видається за весь серіал. Ключів, підписки й власного сервера не потрібно.

Жива перевірка в Lampa: **«Оппенгеймер» — IMDb 8.2, RT 93%, Metacritic 90/100**. Останнього не було у відповіді агрегатора, але його повернув резерв. Старий неповний кеш оновлюється автоматично, особисті оцінки збережені. Результати з’являються поступово. Сервіси не гарантують даних для кожного фільму: відсутні оцінки та неповні лічильники нагород не вигадуються. Оскари й загальні перемоги показуються лише за наявності явних підсумкових даних картки; вони не є додатковими рейтингами.

Запити виконуються для відкритої картки та видимих постерів головної й не блокують кнопки перегляду. Зберігаються максимум 180 записів на 24 години; після помилки — короткий кеш на 5 хвилин. Серіали й фільми мають окремі ключі, відповіді звіряються з IMDb ID. Відомості про відкритий IMDb ID передаються цим сервісам; історія, особисті оцінки, налаштування TorrServer та відео їм не надсилаються. Вимкнення «Рейтинги Faborn → Стандартні» вимикає нові запити. Стан останнього отримання оцінок є у «Версія та діагностика → Рейтинги».

**Список торрентів** отримав SVG-іконки й кольорові бейджі якості, формату, HDR / Dolby Vision, кодека, мов та звуку. Дані беруться з MediaInfo парсера або позначок назви релізу; це характеристики роздачі, а не обіцянка сумісності з телевізором. Виміряна роздільність має пріоритет над назвою. Відомості про озвучення та субтитри зі штатного списку збережені.

- **«Рекомендуємо»** — від 50 сідів за відповіддю парсера. Порядок роздач при цьому не змінюється; кількість сідів не гарантує швидкості.
- **Toloka / Гуртом** — позначка «Пріоритет» і кольорова смуга. Фокус пульта має окремий контрастний контур.
- Розмір виділено окремим бейджем; сіди, піри, бітрейт і дата розділені іконками. Невідома кількість сідів не перетворюється на нуль.
- **Налаштування → ukr by Faborn → Оформлення торрентів** повертає стандартний вигляд. Пошук, фільтри, сортування, наступні сторінки та запуск залишаються штатними; параметри парсера і TorrServer не змінюються.

## Сесія KinoBase — beta.13.1

На пристроях, де KinoBase відхиляє `/user_data` зі статусом HTTP 404, модуль повторює отримання списку через окрему сесію Samsung. Спочатку заново читається сторінка назви, потім сесія й плейлист — в одному сховищі cookie. Звичайний успішний запит додаткового адаптера не завантажує.

**Налаштування → ukr by Faborn → Сесія KinoBase → Автоматично** (типово). Для повернення попереднього способу є «Лише звичайний запит». Резервний спосіб потребує доступного Tizen Sockets у встановленому застосунку. Обробляються тільки метадані KinoBase на телевізорі; локальний порт не відкривається, відео передається AVPlay прямим посиланням. Окремий сервер не потрібен; перемикач експериментального 4K для цього не потрібний.

Якщо KinoBase недоступне, у списку джерел з’являється його стан і причина. Якщо потоки є в іншій якості, рядок підказує доступні якості. «Назад» скасовує запити та повертає фокус картці.

Для «Правдивої терапії» S2E1 живий тест тим самим C-кодом на macOS підтвердив: без cookie `/user_data` повертає 404, з cookie — 200, RU-доріжка до 1080p і доступний HLS. Перевірка на фізичному Samsung ще потрібна: наявність WebAssembly сама по собі не гарантує Tizen Sockets у конкретній збірці Lampa.

Скляні поверхні, м’які відблиски й округлі кнопки оформлюють верхнє меню, бічну навігацію, кнопки картки, налаштування, списки вибору, діалоги, клавіатуру, сповіщення та елементи керування плеєром. Ефекти не застосовуються до відеоплощини AVPlay; немає зовнішніх шрифтів, бібліотек чи додаткових мережевих запитів теми. Перевірено в браузері зі справжнім ядром Lampa; плавність на фізичному телевізорі ще потрібно оцінити.

## Оформлення

**Налаштування → ukr by Faborn:**

- **Оформлення модуля:** «Панель» — компактне вікно поверх картки; «Кінозал» — велике вікно з назвою, зображенням TMDB (якщо воно є) та описом. **«Стандартне Lampa»** — штатні списки джерел і серій та нейтральний фокус, без кольорових акцентів, градієнтів і глобальної теми Faborn. Додаткові функції працюють за власними перемикачами. Перемикання діє одразу. Раніше цей пункт називався «Стандартний список».
- **Тема всієї Lampa:** Faborn, iOS · Liquid Glass або стандартна Lampa. Для «Панелі» й «Кінозалу» окремо оформлює меню, кнопки картки, фокус постерів, налаштування, списки вибору й діалогові вікна. Вимкнення прибирає глобальні стилі Faborn без зміни налаштувань Lampa.
- **Колір акценту:** чотири суцільні кольори та два градієнти — **синій → фіолетовий** і **бірюзовий → синій**. У beta.9 градієнти насиченіші, з окремим контрастним кольором тексту. Градієнти застосовуються до кнопок, фокуса та смуг прогресу; Фокус кнопок позначений кольором без обводки. Акцент і глобальна тема застосовуються одразу; обраний вигляд модуля — під час наступного відкриття.

За замовчуванням: панель, тема Faborn, синій акцент. Для «Панелі» й «Кінозалу» глобальну тему можна перемикати окремо. «Стандартне Lampa» вимикає глобальну тему Faborn і надає додатковим блокам нейтральне оформлення; збережені колір і тема відновлюються при поверненні до «Панелі» або «Кінозалу». Власні налаштування Lampa та теми інших розширень не змінюються. Стилі модуля включені в головний JS-файл; оформлення головної, рейтингів і торрентів завантажується з `lib/faborn-ui.js` того самого GitHub Pages. Аналізатор KinoBase завантажується з того самого GitHub Pages; додаткові шрифти або сервер не потрібні. Тема оформлює Lampa, а не меню операційної системи Samsung. Відеоплощина Tizen залишається під керуванням Lampa.

## Перегляд

**Картка TMDB → іконка F Faborn → переклад або джерело → плеєр.** На кнопці модуля залишається тільки іконка; доступна назва для допоміжних технологій збережена. Велика кнопка «Дивитися» запускає перше джерело вибраного перекладу з урахуванням пріоритету джерела.

Модуль сам шукає українську й, за потреби, оригінальну назву на **UAKino, UASerials, UAFix та KinoBase**, перевіряє метадані сторінки й читає потоки. Якість обирається кнопками у тому самому вікні. Нижче — по одному рядку на переклад. Українські доріжки позначені **UA**, російські — **🐷 RU**; у «Панелі» та «Кінозалі» іконка векторна й не залежить від підтримки емодзі телевізором. Підтверджені англійські доріжки позначені EN. Порядок мов: UA, EN, оригінал невідомою мовою, RU. Напис «Оригінал» стає EN лише за наявності англійської оригінальної мови в TMDB. Однакові назви перекладів однією мовою згруповані між джерелами; номер плеєра не створює окремого перекладу. Якщо джерело одне, натискання запускає його. Якщо кілька — кнопки джерел розгортаються під перекладом; натискання джерела одразу запускає його.

Якість запам’ятовується. За замовчуванням — найвища доступна; якщо збереженої якості немає, обирається найближча нижча або найнижча доступна. Перемикання якості змінює перелік доступних перекладів без повторного пошуку. 4K показується лише для наявного 2160p. «Назад» закриває вікно й повертає керування картці.

Для серіалу є окремі кнопки **«Сезон …»** та **«Серія …»**. Модуль запам’ятовує останню фактично переглянуту серію; саме відкриття списку або невдалий запуск її не змінює. Наступна серія поки обирається вручну; неперевірені посилання не додаються до автоплейлиста. За наявності прогресу Lampa він показується у вікні. «Продовжити з …» з'являється лише коли в плеєрі увімкнено продовження та запис ще не переглянутий до кінця; глобальний режим тайм-коду не змінюється.

### Серії та історія

Натисни **«Серія …»**: у «Панелі» та «Кінозалі» відкриються кадри, назви й короткі описи TMDB. Для кожного епізоду показані таймкод, смуга прогресу або «Переглянуто» від 90%. У стандартному списку також є кадри, назви, короткі описи та текстовий прогрес. Відсутність кадру чи відповіді TMDB не блокує вибір епізоду.

**«Ви дивилися S…E…»** повертає до останньої переглянутої серії, навіть після перегляду іншого сезону в меню. Прогрес окремий для кожного епізоду та спільний між озвученнями й джерелами. Збережені таймкоди beta.9 читаються; нові позначки також передаються стандартній історії Lampa. Запис додається до **Історії Lampa** після фактичного початку відео, прогрес зберігається приблизно кожні 15 секунд та при виході. Синхронізацію між пристроями визначає сама Lampa.

### Субтитри

Доступні доріжки вибираються кнопкою **CC / «Субтитри» у плеєрі Lampa**. Якщо джерело віддало зовнішні доріжки, їхні назви видно під кнопкою запуску. Підтримано SRT/VTT із відкритих конфігурацій, успадкування субтитрів зі списків сезонів і нативні доріжки HLS. Порожній список більше не перекриває субтитри Tizen. Якщо джерело їх не надає, модуль не створює й не перекладає субтитри автоматично.

### Англійський оригінал

Beta.10 показує EN там, де наявне джерело справді віддає англійську доріжку. **Нового окремого англомовного сервісу в цій версії ще немає.** У переглянутих адаптерах VidSrc/VidLink/Videasy потік отримується через браузерний обробник на сервері, а відкриті сторінки VidSrc повернули iframe; HDRezka повернув перевірку браузера на сторінці фільму. Прямий HLS для нашої схеми «GitHub Pages → Tizen» з нового сервісу не підтверджений. У перевірених KinoBase «Оппенгеймері», «Друзях», The Office, The Big Bang Theory та Stranger Things англійська доріжка не знайдена.

Зіставлення виконується за українською/оригінальною назвою, типом і роком. Різниця року до одного враховує прокатні дати. Рік пізнішого сезону UAKino може відрізнятися від року початку серіалу TMDB. Приблизний збіг із пошуку додатково перевіряється за повною сторінкою, щоб не запустити інший фільм.

### KinoBase

Публічний плеєр KinoBase працює через анонімну cookie-сесію. У beta.10 сторінки кандидатів читаються послідовно: одночасне відкриття схожих фільмів замінювало cookie й давало HTTP 404, зокрема для «Оппенгеймера». Модуль читає актуальні параметри запитів зі структури JS, отримує HLS та оновлює тимчасові посилання перед запуском, якщо минула хвилина. Кеш одного списку живе тільки в пам’яті. Оновлення зберігає конкретне озвучення, сезон і серію; зникла доріжка не замінюється іншою мовою. Дзеркала не дублюються у вікні й перевіряються по черзі при помилці.

Для HLS з окремим аудіо плеєру передається повний master-плейлист. KinoBase може мати окремі master-посилання для кожної якості й аудіодоріжки. Це зберігає звук та ручний вибір якості.

Не всі сторінки KinoBase містять прямий плеєр: сторонні iframe-балансери поки не підтримуються. Зміна протоколу сайту, cookie-обмеження, мережеві блокування або несумісний кодек можуть зробити конкретне відео недоступним. Це відображається в діагностиці й не блокує інші джерела.

**Перевірено 30.09.2026 кодом beta.9:** «Термінатор 2» — 3840×2160 з окремою аудіодоріжкою; «Назад у майбутнє» — 1920×1040; «Друзі» — 10 сезонів, 1280×720, зокрема UA 1+1 та RU Paramount Comedy/РТР. Мова визначена з назв доріжок; перевірка HLS не замінює перегляд на фізичному телевізорі.

## Навігація та помилки

«Назад» скасовує запити й повертає керування картці. Повторний пошук, перехід між сезонами та запізнілі мережеві відповіді не повинні залишати фокус у прихованому меню. Перед запуском плеєра також відновлюється контролер картки, щоб його закриття повертало користувача до Lampa.

Окремий запит має таймаут 12 секунд; загальний пошук обмежений 24 секундами, перевірка обраної серії — 20 секундами. Показуються отримані робочі варіанти; відмова одного джерела не скасовує інші. Посилання, старше хвилини, повторно читається з плеєра. Маніфест вибраної якості перевіряється безпосередньо перед запуском.

Діагностика доступна в налаштуваннях, без додаткового мережевого запиту: версія, плеєр, AVPlay, стан джерел, останні етапи пошуку та помилка відтворення. Відомості зберігаються локально в Lampa. Якщо відео не запустилося за 45 секунд, є повтор і вибір іншого джерела/якості. Глобальні налаштування плеєра не змінюються.

## GitHub

GitHub Pages віддає головний JS, `lib/faborn-ui.js`, `lib/kinobase.js` і резервний JSON. Аналізатор використовує зафіксований Acorn 8.18.0 (MIT), розміщений у цьому ж репозиторії; код стороннього плеєра не виконується. При ручному копіюванні обов’язково зберігай каталог `lib/`. Пошук і читання нових сторінок виконує телевізор; відео надходить із відеохостів. Для онлайн-джерел проксі, VPS або TorrServer не потрібні. Окрема кнопка торрентів використовує налаштований користувачем TorrServer. GitHub не виконує запити на вимогу телевізора.

Резервний індекс із 3 назв («Бджоляр», «Профі», «Річер», сезон 3) автоматично доповнює результати відповідних карток. Він не обмежує пошук цими назвами. Actions оновлює його після push та приблизно кожні 30 хвилин. Кнопка «Оновити індекс із GitHub» читає готовий JSON і не запускає Actions.

Для власної копії: завантаж файли разом із `.github/`, увімкни **Settings → Pages → Source → GitHub Actions**, дочекайся build/deploy. Головна сторінка Pages покаже адресу JS. Для відкату поверни файли попереднього релізу та опублікуй Pages.

## Перевірки

Python 3.10+, Node.js 20+, C-компілятор і заголовки/бібліотека libcurl для перевірок локального каналу; без додаткових pip/npm залежностей. На Ubuntu потрібен `libcurl4-openssl-dev`; на macOS достатньо Command Line Tools. SDK Samsung потрібен лише для повторної збірки WASM:

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/build_resolver.py
node --test tests/test_*.js
node --check ukr-by-faborn.js
python3 scripts/validate.py
```

Докази та межі перевірки — `VALIDATION.md`. Користувач підтвердив роботу beta.6 на телевізорі. Оформлення та навігацію beta.9 перевірено у справжньому ядрі Lampa з контрольованими відповідями джерел; новий адаптер потребує перевірки на фізичному Samsung. Браузерна перевірка не замінює Tizen / AVPlay.
