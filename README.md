# ukr by Faborn — 0.1.0-beta.3

Технічна бета розширення Lampa для Samsung Tizen. Окрема синьо-жовта іконка **ukr by Faborn** у картці фільму/серіалу, українські релізи з UAKino та KinoUkr, онлайн HLS з Ashdi.

**Критична межа перевірки:** у браузерній Lampa відео не запустилося: сегменти Ashdi дозволяють CORS лише для `https://ashdi.vip`. Ця збірка призначена для перевірки **штатного плеєра Tizen / AVPlay на телевізорі**. Такий шлях є в коді Lampa, але успішне відтворення на Samsung ще не підтверджене. GitHub Pages / Actions не можуть самі усунути обмеження відеосервера. Бета не видається за гарантовано працездатний онлайн-модуль.

## Оновлення встановленого розширення

Залиш наявну адресу розширення. Постійне посилання:

```text
https://serg-ill.github.io/ukr-by-faborn/ukr-by-faborn.js
```

Повністю закрий і знову запусти Lampa. Редагувати URL або додавати другу копію не потрібно; стара адреса з `?v=…` також відкриває поточний файл. Lampa додає до запиту власний параметр оновлення. У меню модуля або «Версія та діагностика» має бути `0.1.0-beta.3`. Якщо версія залишилася старою, застосунок міг не перезапуститися або Lampa використала кеш після мережевої помилки.

Beta.3 виправляє підтверджене падіння налаштувань `Cannot read property '' of undefined`: текстове поле адреси не передавало обов’язковий параметр `values` до Lampa. Діагностика тепер доступна також безпосередньо з меню `ukr by Faborn` у картці. Додано перехоплення помилки з об’єкта нативного плеєра, оскільки адаптер Tizen передає її в `event.error`, а загальний обробник Lampa читає `video.error`. Це допомагає побачити причину невдалого старту, але не підтверджує виправлення самого відтворення на Samsung.

У beta.1 були підтверджені застарілі адреси «Бджоляра»: маніфести відкривалися, а їхні відеосегменти вже повертали HTTP 404. Сторінка Ashdi видала нові адреси. Beta.2 повторно читає опублікований індекс перед кожним ручним запуском; кеш списку назв живе не довше хвилини. Розклад Actions змінено на кожні 30 хвилин. Під час помилки старту модуль показує її повідомлення, а якщо плеєр не повідомив про завантаження відео протягом 45 секунд — закриває завислий запуск і пропонує повтор або іншу якість.

Це скорочує період використання старих адрес, але **не дає миттєвого оновлення з Ashdi**: між зміною адреси та наступним успішним Actions залишається проміжок. Якщо адреси змінилися під час перегляду серіалу, вийди з плеєра й повторно відкрий серію, щоб отримати оновлений плейлист.

## Що входить у цю бету

Індекс навмисно обмежений **3 назвами / 18 відеопотоками**:

| Назва | Джерело | Озвучення | Обсяг |
|---|---|---|---|
| Бджоляр / The Beekeeper (2024) | UAKino | Український дубляж | 4K, 1080p, 720p, 480p |
| Профі / A Working Man (2025) | KinoUkr | Український дубляж | 4K, 1080p, 720p, 480p |
| Джек Річер / Reacher (2022) | UAKino | DniproFilm та Uaflix | Сезон 3, серії 1–8 у кожному озвученні |

**Це не пошук по всьому каталогу сайтів.** Картки інших фільмів покажуть повідомлення про відсутність у бета-індексі, ручний пошук або весь доступний індекс. Сезони 1, 2 та 4 «Річера» сюди не включені.

Доступність потоків змінюється. В beta.1 S03E08 у DniproFilm повертала HTTP 404; після зміни адреси її сегмент знову став доступним. Поточний результат перевірки — у `data/status.json`; недоступні записи позначаються в меню. Перевірка першого сегмента підтверджує доступ до даних, але не декодування всього відео на телевізорі. Плейлист зупиняється перед відсутньою/недоступною серією і не перестрибує через неї.

Є вибір джерела/озвучення, сезону, серії, фактичної якості; плейлист наступних серій; українські субтитри, коли вони є в релізі; інтеграція з Lampa Timeline; запам’ятовування останньої серії та бажаної якості. Автоперехід до наступної серії керується штатним налаштуванням Lampa для плейлиста. Мову аудіо підтверджено описами джерел, не автоматичним розпізнаванням звуку.

## Тільки GitHub — як це працює

```text
GitHub Actions -> читає перевірені сторінки Ashdi -> формує JSON-індекс
GitHub Pages   -> ukr-by-faborn.js + data/catalog.json -> Lampa
Ashdi          -> HLS-відео безпосередньо на телевізор
```

Стороннього API, VPS, проксі або TorrServer немає. Саме відео не завантажується й не зберігається на GitHub. У пакеті немає токенів, паролів або прив’язки до чужого репозиторію.

Пряме читання HTML сайтів із вебзастосунку обмежується CORS; автоматичні запити UAKino під час складання повертали Cloudflare 403. Тому адаптери працюють **під час оновлення в GitHub Actions**, а телевізор читає готові дані зі свого GitHub Pages. Перевірені HLS-маніфести Ashdi повернули `Access-Control-Allow-Origin: *`, проте сервер відеосегментів — `Access-Control-Allow-Origin: https://ashdi.vip`. Саме тому браузерний HLS-плеєр не працює з іншої адреси.

Actions оновлює потоки для заздалегідь перевірених записів `config/sources.json`. Якщо доступна сторінка джерела, адаптер також звіряє iframe/посилання відомих серій. Бета не обходить захисні перевірки, не входить в облікові записи та не виявляє автоматично всі нові назви/серії. Додати нову назву можна через явний запис у `config/sources.json` із підтвердженим українським озвученням.

## Встановлення на власний GitHub

1. Розпакуй ZIP. Створи **публічний** репозиторій, наприклад `ukr-by-faborn`, з основною гілкою `main`.
2. Завантаж **вміст папки пакета в корінь репозиторію**. Файли `ukr-by-faborn.js`, `index.html`, `data/`, `config/`, `scripts/`, `tests/`, `assets/` та прихована `.github/workflows/pages.yml` мають бути збережені. На macOS приховані файли показуються через `Command + Shift + .`.
3. У репозиторії відкрий **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Відкрий **Actions → Build and publish Faborn beta → Run workflow**. Дочекайся успішних `build` і `deploy`.
5. Відкрий адресу Pages, яку покаже GitHub. Головна сторінка виведе **готове посилання саме для твого репозиторію**.
6. Додай це посилання в **Lampa → Налаштування → Розширення → Додати** та перезапусти Lampa.

Шаблон адреси (USERNAME та REPOSITORY — замінники, не готова адреса):

```text
https://USERNAME.github.io/REPOSITORY/ukr-by-faborn.js
```

Не додавай адресу сторінки файлу виду `github.com/.../blob/...` і не завантажуй у репозиторій лише ZIP. Беті потрібні JS та JSON поруч на Pages. Розширення саме визначає базову адресу з URL свого скрипту; резервне поле є в його налаштуваннях.

GitHub workflow запитується кожні 30 хвилин та після змін у `main`; можливий ручний запуск. Виконання розкладу залежить від GitHub. Якщо workflow вимкнений або сайт відмовляє в доступі, нові дані не з’являться. Кнопка «Оновити індекс із GitHub» на телевізорі лише повторно читає вже опублікований JSON, а не запускає Actions.

## Перша перевірка на Tizen

Спочатку у налаштуваннях плеєра Lampa обери **Tizen** (штатний Samsung AVPlay). Якщо такого пункту немає, ця збірка не підходить для перевірки прямого відтворення в цій інсталяції Lampa. Модуль сам не змінює глобальний вибір плеєра.

1. Відкрий картку «Бджоляр» (2024) → **ukr by Faborn** → реліз → **4K · 2160p**. Перевір український звук, запуск, паузу та перемотування.
2. Аналогічно запусти «Профі» (2025). Перевір субтитри та 1080p/4K.
3. Відкрий картку серіалу «Річер» (2022), а не однойменного фільму. Обери сезон 3, потрібну озвучку та серію. Перевір наступну серію через плейлист.
4. Вийди з відео та відкрий його знову. Позицією керує штатний Lampa Timeline та налаштування продовження перегляду.
5. Для тесту невідомої назви відкрий будь-який фільм поза індексом — модуль має повідомити про це, а не підставити інше відео.

Код JS написаний у синтаксисі ES5; підтримка конкретних відеокодеків, звуку та 4K залежить від плеєра й телевізора. На фізичному Samsung Tizen цю збірку ще не перевірено. 4K у двох тестових фільмах — реальний кадр 3840×1600, широкий кіноформат без чорних смуг у кадрі. Позначки HDR/5.1 не додаються лише за назвою файла.

## Помилки та оновлення

- **Немає кнопки:** перевір, що URL закінчується `ukr-by-faborn.js` і відкриває JavaScript, потім перезапусти Lampa. У новому інтерфейсі кнопка має бути поруч із «Дивитися».
- **Не знайдено назву:** у поточній беті лише три назви. Пошук також підтримує оригінальні назви.
- **Помилка відкриття налаштувань:** повністю перезапусти Lampa і перевір номер beta.3 через кнопку `ukr by Faborn` у картці. Пункт «Версія та діагностика» доступний і в цьому меню.
- **Не завантажується індекс:** відкрий `data/catalog.json` за своєю адресою Pages, перевір workflow та поле «Адреса GitHub Pages» в налаштуваннях модуля.
- **Потік недоступний:** запусти workflow у GitHub, потім «Оновити індекс із GitHub» у Lampa. Якщо адреса не змінилася, перевір інше озвучення/джерело. Два каталоги можуть посилатися на один і той самий Ashdi.
- **Застарілий запис:** `data/status.json` містить результати перевірки, а `updatedAt` у записі — дату останнього успішного оновлення. Помилка не замінює цю дату на нову.

Для оновлення версії заміни файли репозиторію новим пакетом, дочекайся workflow та перезапусти Lampa. Постійна адреса розширення зберігається. Для відкату поверни попередню версію файлів у GitHub і повторно запусти workflow. Щоб видалити модуль, видали його URL зі списку розширень і перезапусти Lampa.

## Перевірки розробника

Потрібні Python 3.10+ та Node.js 20+. Залежності pip/npm не потрібні.

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/test_plugin.js
node --check ukr-by-faborn.js
python3 scripts/build_catalog.py
python3 scripts/validate.py
```

Детальні результати складання — у `VALIDATION.md`; контрольні суми файлів пакета — у `SHA256SUMS.txt`. [GitHub Actions](https://github.com/serg-ill/ukr-by-faborn/actions) показує стан публікації. JSON на Pages оновлюється після складання й може відрізнятися від пакета. Відтворення виправленої версії на фізичному телевізорі ще потрібно підтвердити.
