# ukr by Faborn — 0.1.0-beta.33

Розширення Lampa для Samsung Tizen. Код і резервний індекс розміщені на GitHub Pages; окремий сервер не потрібен. Відео відтворюється через Tizen / AVPlay.

## Моя медіатека та керування коментарями — beta.33

**«Моя медіатека»** замінює пункт «Мої серіали» у боковому меню. Угорі дві вкладки: **«Фільми» / «Серіали»**. Усі збережені серіали, відмітки, прогрес і сповіщення залишаються; вибрана вкладка відновлюється після перезапуску.

Для фільмів є групи **«Хочу подивитися»** та **«Переглянуто»**. Фільми, які хочеш подивитися, завжди стоять першими у фільтрі «Усі»; кожну групу можна відкрити окремо. Натисни іконку медіатеки в картці фільму та вибери групу. Додавати також можна з пошуку або історії; **довге OK** на фільмі в медіатеці відкриває зміну групи та видалення зі списку. Видалення не стирає час зупинки чи історію Lampa.

Коли прогрес фільму досягає **80%**, він автоматично додається до **«Переглянуто»**, навіть якщо його не було в медіатеці. Наявний фільм із «Хочу подивитися» переходить у «Переглянуто» без дубля. Потрібні картка фільму й події прогресу від плеєра Lampa або Timeline: це підтримує онлайн і штатний запуск торрентів. Серії, трейлери та відео без достовірної прив’язки до фільму не додаються. Правило діє під час подальшого перегляду; стару історію можна додати вручну. Списки локальні, окремі для кожного профілю, до 500 фільмів і 120 серіалів. **«Переглянуте та перенесення»** у налаштуваннях копіює також відсутні фільми з іншого збереженого профілю на цьому пристрої; поточні групи й прогрес не перезаписуються.

**Налаштування → ukr by Faborn → Коментарі в картці:** **«Лише з джерел»**, **«Лише Lampa»**, **«Усі»** або **«Приховати всі»**. Початковий режим — лише джерела; якщо раніше їх явно вимкнули, зберігаються лише штатні коментарі. Після зміни повторно відкрий картку. Приховані блоки не залишають порожнього місця в навігації.

## Коментарі з джерел — beta.32

Faborn сам читає публічні відгуки зі сторінок **UAFix** та **UASerials**. У картці фільму / серіалу під описом з’являється окремий ряд **«Коментарі з джерел»**: автор, дата сайту, реакції, назва джерела та до чотирьох рядків тексту. **OK** — повний відгук, **Назад** — на той самий коментар. Позначені сайтом спойлери відкриваються лише після **«Показати спойлер»**; непозначені спойлери автоматично не визначаються.

Завантаження починається при переході до ряду, незалежно від запуску відео. Показуються до 24 відгуків із перших сторінок джерел; остання картка дозволяє оновити їх. Відповіді позначені окремо, джерела чергуються. Кеш у пам’яті до 4 годин і повторне використання вже знайдених сторінок зменшують кількість запитів. Помилки доступу / CORS / TLS показуються як недоступність сайту, а не як відсутність відгуків; окремого сервера або проксі не потрібно, доступ залежить від застосунку та мережі.

У beta.33 показ обох блоків регулює **Налаштування → ukr by Faborn → Коментарі в картці**. Після зміни повторно відкрий картку. Режим «Усі» залишає штатні коментарі CUB окремим рядом. Інтеграція призначена для читання: публікувати відгуки чи ставити реакції на сайтах вона не може. Підтримуються поточні збірки Lampa з API Maker; в старих збірках без нього ряд не додається.

## Компактні коментарі — beta.31

У картці фільму чи серіалу штатні коментарі Lampa мають компактні горизонтальні прев’ю: автор і реакції зверху, до чотирьох рядків тексту та підказка **«OK — читати»**. На тестовому екрані 1280×720 вміщуються три повні коментарі. **OK** відкриває повний текст; **Назад** повертає на вибраний відгук. Окремий список повних коментарів залишається штатним.

Оформлення автоматично підлаштовується під Faborn, iOS або стандартну Lampa. Замість відсутнього аватара — локальна іконка, кнопка додавання теж компактна. Додаткових запитів чи фонових таймерів немає.

## Навігація та швидкодія «Моїх серіалів» — beta.30

Над картками й під списком з’явилася окрема панель: **«Попередня сторінка» / «Наступна сторінка»**, номер сторінки та діапазон серіалів. Наступна сторінка виділена акцентом теми; у стандартній Lampa — нейтральним контрастним кольором. Після переходу фокус пульта стає на перший серіал нової сторінки.

Підрахунки прогресу та метадані повторно використовуються між сторінками й фільтрами. Відповіді сервісу оновлюють потрібні частини карток без повної перебудови списку. Після зміни відміток, профілю або дня прогрес перераховується. Кнопка «Оновити» залишається для примусової перевірки даних.

## Переглянуте та перенесення — beta.29

У **«Моїх серіалах» → «Переглянуте»** можна позначити весь серіал станом на сьогодні, окремий сезон або всі епізоди до обраного включно. Дія також доступна в меню іконки **«✓»** у картці та довгим натисканням **«+» / «✓»** або серіалу в центрі. Перед збереженням показується кількість епізодів. Дати перевіряються за TMDB: майбутні, недатовані серії й спецвипуски не позначаються. Якщо отримати дані сезону не вдалося, відмітки не змінюються.

Відмітки потрапляють до штатного Timeline Lampa й спільних ключів Faborn: їх бачать серії, постери та прогрес онлайну / торрента. Для поточного завершеного сезону й переглянутої останньої випущеної серії незавершеного серіалу показується **«Очікуємо нових серій»**; такий серіал залишається у фільтрі **«Очікуються»**, навіть якщо наступна дата ще невідома. Новий епізод надалі залишиться непроглянутим. У **«Переглянуте» → «Скасувати останні відмітки»** доступне відновлення попереднього прогресу; подальший перегляд або новіші зміни не перезаписуються. Скасування стосується прогресу, а не видалення серіалів зі списку.

**Після зміни акаунту:** Lampa використовує окремий Timeline кожного профілю; Faborn теж зберігає окремі списки. У **«Переглянуте» → «Перенести з іншого профілю»** можна явно скопіювати збережені на цьому пристрої відмітки й список Faborn. Джерело залишається без змін; у поточному профілі заповнюються лише відсутні записи, збережені скидання й поточний прогрес захищені. Показується кількість записів прогресу та серіалів (записи можуть містити кілька ключів одного епізоду).

Ті самі дії доступні через **Налаштування → ukr by Faborn → Переглянуте та перенесення**. Це локальне копіювання, не новий сервіс синхронізації: якщо кеш старого профілю видалений, був на іншому пристрої або не завантажувався сюди, його неможливо відновити цим способом. У такому разі використовуй швидке позначення сезонів.

## Повторний перегляд і нові серії — beta.28

**Швидкий повторний перегляд:** відкрий панель плеєра й вибери кругову стрілку **«З початку · 00:00»** поруч із Play / Pause. У вікні джерел Faborn також є **«З початку»**, коли збережений прогрес, навіть якщо фільм уже завершений. Дія працює в Панелі, Кінозалі й стандартному списку Lampa; скидає лише поточний фільм або серію. Спільна позиція онлайну / торрента змінюється після фактичного переходу плеєра до початку. Якщо запуск не вдався, попередня позиція зберігається. Штатне налаштування продовження перегляду не змінюється.

**Дата нової серії:** у картці серіалу та у вкладці «Мої серіали» з’являється компактний бейдж **«Нова серія сьогодні / завтра / через 3 дні»** з номером сезону, серії та датою. Після недавнього виходу може показуватися «Вийшла нова серія». Якщо TMDB не має дати, відліку немає.

**Сповіщення:** натисни «+» у картці серіалу, щоб стежити за ним. Перша перевірка запам’ятовує поточний стан; про наступний новий епізод модуль повідомить один раз у меню Lampa. Перевірка виконується раз на 6 годин, поки застосунок працює; повідомлення чекає закриття відео та списку вибору. Вже переглянуті епізоди не спричиняють повідомлення. Список і стан сповіщень окремі для кожного профілю. При вимкненому телевізорі або закритій Lampa сповіщення не надсилаються.

**Налаштування → ukr by Faborn → «Відлік до нової серії» / «Сповіщення про нові серії»**: два незалежні перемикачі, початково ввімкнені. Дати беруться з TMDB: це дата виходу епізоду, а не підтвердження доступності потоку чи українського озвучення. Додатковий сервер не потрібен.

## Центр серіалів і добірки — beta.27

У боковому меню — дві незалежні вкладки:

- **Що подивитися**: настрій, до 90 / 120 / 180 хвилин або без обмеження, мінімальна оцінка TMDB, виключення вже переглянутого. Після натискання — три фільми з рейтингом, тривалістю й описом; «Ще три варіанти» пропонує інші назви. Вибір відкриває звичайну картку Lampa з джерелами Faborn.
- **Мої серіали**: власний список, остання серія та прогрес зі спільної історії онлайну / торрента, непроглянуті епізоди поточного сезону, відома дата наступного епізоду. Фільтри: усі, продовжити, є непроглянуті, очікуються.

**Як додати:** у картці серіалу натисни нову іконку **«+» — «Стежити за серіалом»**. Вона зміниться на **«✓»**. Повторне натискання відкриває перехід у центр або видалення зі списку. Історія, прогрес і відмітки перегляду при видаленні зберігаються. У центрі також є **«Додати серіал»** із пошуком та **«Додати з історії»**: кожний серіал додається лише після вибору. Довге натискання на серіал у центрі відкриває керування ним.

Список зберігається на пристрої для поточного профілю Lampa (до 120 серіалів). Окремої синхронізації цього списку між телевізорами немає. Дати й метадані беруться з TMDB; вихід епізоду не означає наявності потоку або потрібного озвучення. Рекомендації також не гарантують доступності відео: джерела перевіряються у картці. Якщо TMDB недоступний, можна повторити запит; серіали залишаються у збереженому списку.

**Налаштування → ukr by Faborn → Вкладка «Що подивитися» / Вкладка «Мої серіали»** дозволяють приховати будь-яку вкладку. Вони працюють зі стандартним оформленням Lampa, темами Faborn та iOS; кнопка стеження в картці залишається лише іконкою.

Обидва акваріуми видалені зі стилів заставки разом із графікою та відеоджерелом. Збережений вибір `aquarium` або `aquarium-video` переводиться на Аврору. Налаштування часу запуску, годинника й режиму заставки зберігаються.

## Відновлення автопереходу — beta.24.1

Черга серій повторно встановлюється при кожному запуску відео. Якщо після події завершення Lampa не почала перехід, модуль відновлює плейлист, отримує та перевіряє свіжий потік наступної послідовної серії й передає його штатному плеєру. Зберігаються сезон, озвучення й вибір якості. Звичайний перехід Lampa має пріоритет; резервний обробник не запускає серію вдруге. Вихід «Назад» скасовує незавершені запити та повертає до наявного списку джерел.

Штатний перемикач **Lampa → Плеєр → Наступна серія** залишається обов’язковим. Відкрите меню плеєра призупиняє автоперехід. У **«Версії та діагностиці»** додано версію Lampa та рядок **«Автоперехід»**: поточна / наступна серія, довжина черги й останній етап переходу або помилка.

Перевірено справжній плейлист UASerials «Юний Шелдон» у ядрі Lampa з імітацією AVPlay: звичайний перехід, навмисна втрата штатного плейлиста та повернення до джерел. Причину збою на конкретному Samsung ще не підтверджено. Резервний перехід спирається на подію завершення відео; час кінця не вгадується. Якщо чорний екран повториться, рядок «Автоперехід» покаже, чи надійшла ця подія й чи почалося отримання наступного потоку.

## Мітки джерел і компактний хедер — beta.24

**Налаштування → ukr by Faborn → Пропуск за мітками джерела.** Окремий перемикач, початково вимкнений. Модуль читає явні інтервали `skip` з відкритої конфігурації PlayerJS у вже підтримуваних джерелах Ashdi / HDVB та з окремих елементів плейлиста KinoBase. Новий адаптер HDRezka не додається. [Формат міток PlayerJS](https://playerjs.com/docs/en=skipbutton).

Якщо джерело не позначає тип відрізка, кнопка має назву **«Пропустити фрагмент»**. Вона з’являється лише в межах його мітки: відлік **7 секунд**, **OK** — пропустити зараз, **Назад** — скасувати без виходу з відео. Пропуск веде точно до кінця позначеного фрагмента; його тип не вгадується й серія не позначається завершеною лише через таку мітку.

Придатні мітки джерела мають пріоритет. Якщо їх немає або вони не відповідають тривалості відео, залишається IntroDB за ввімкненими налаштуваннями вступу / титрів. Вмикання лише нового перемикача не вмикає IntroDB. Мітки двох джерел не змішуються для одного відео. Мітки папки чи сезону не поширюються на всі серії; після зміни серії, озвучення або якості беруться дані вибраного потоку, а попередні очищаються.

Жива перевірка двох сторінок Ashdi не знайшла таких міток: нова підтримка **не гарантує пропуск у кожному відео**. Перевірено парсинг, передачу до плеєра, відлік, скасування, наступну серію та резерв IntroDB у справжньому ядрі Lampa з тестовими метаданими й імітацією AVPlay. Відтворення на фізичному Samsung ще не перевірене. Окремий сервер і відеопроксі не потрібні.

Хедер вікна джерел став компактнішим приблизно на **20%**. Градієнт більше не фарбує нижній роздільник і не обводить шапку рамкою; в iOS залишається власний скляний роздільник. Іконка й кнопка закриття зберігають розмір, довга назва не витісняє хрестик.

## Серії, повернення до джерел і пропуск за мітками — beta.23

Після завершення серії запускається наступна **в тому самому сезоні та озвученні**, якщо її віддало джерело й у Lampa увімкнено штатний автоперехід до наступної серії. Пропуски номерів і недоступні серії не перескакуються. Посилання наступної серії оновлюється й перевіряється перед запуском; зберігається вибрана якість або береться доступна нижча. Кнопки плейлиста у плеєрі теж працюють.

**Назад із плеєра** повертає до збереженого вікна джерел на поточній серії, без повторного пошуку сайтами. Фокус — на виборі серії; після вибору — одразу на «Дивитися». Працює в «Панелі», «Кінозалі» й стандартному вікні Lampa. Завершена серія записується як переглянута, наступна не отримує її завершений прогрес.

**Налаштування → ukr by Faborn → Пропуск вступу за мітками / Пропуск титрів за мітками.** Обидва перемикачі початково вимкнені. Сім секунд — час відліку кнопки, а не початок вступу чи довжина пропуску. Пауза, очікування відео й діалог продовження не витрачають відлік.

Для Samsung використовується прямий HTTPS-запит метаданих і резерв через вбудований адаптер Samsung, якщо доступний мережевий API застосунку. Сервер користувача й відеопроксі не потрібні. Браузер може блокувати API через CORS; фізичне відтворення на телевізорі потребує перевірки.

Вперше знайдена роздача отримує зв'язок із серіями після відкриття списку файлів. Різні монтажні версії або заставки можуть мати зміщення: переноситься час у секундах, без аналізу кадрів.

Стороння роздача, саундтрек або ремейк іншого року не доповнюють картку. Порожнє місце не заповнюється вигаданою якістю. Кеш — до 24 годин, без посилань, magnet і ключів.

**Toloka / Гуртом** виділено кольоровою смугою зліва та позначкою **«Пріоритет»**, без чорної рамки. Це окремо від рекомендації за сідами: Toloka лишається виділеною і при невеликій їх кількості. Штатне сортування збережене.

Для Dolby використовується оригінальний векторний знак і фірмовий напис з офіційного сайту, поруч — назва формату. **Vision** стосується відео, **Audio / Atmos** — звуку. Atmos з'являється тільки за прямою позначкою у метаданих або назві релізу з Dolby-кодеком; AC-3, E-AC-3, TrueHD чи 7.1 самі по собі не означають Atmos. Форматні бейджі не використовують зірочки. [Джерело вектора та торговельні марки](ASSET_NOTICES.md).

## Рейтинги та дані релізів

Панель рейтингів зменшена приблизно на **37% заввишки**, зі збереженням іконок, назв сервісів і шкал. У beta.14 вона лише оформлювала дані, вже наявні в картці: без іншого постачальника оцінок часто залишалися тільки TMDB та «Оцінити».

Модуль отримує IMDb ID з TMDB, а за ним — **IMDb через [Cinemeta](https://v3-cinemeta.strem.io/manifest.json)** та доступні **Rotten Tomatoes / Metacritic через [Ratings Aggregator](https://rating-aggregator.elfhosted.com/)**. У beta.16 додано резерв через відкриті дані [Wikidata](https://www.wikidata.org/): спочатку точне зіставлення IMDb ID, потім оцінки з перевіркою сервісу, шкали, методу й дати. Оцінки глядачів не видаються за оцінки критиків, оцінка окремого сезону не видається за весь серіал. Ключів, підписки й власного сервера не потрібно.

Жива перевірка в Lampa: **«Оппенгеймер» — IMDb 8.2, RT 93%, Metacritic 90/100**. Останнього не було у відповіді агрегатора, але його повернув резерв. Старий неповний кеш оновлюється автоматично, особисті оцінки збережені. Результати з’являються поступово. Сервіси не гарантують даних для кожного фільму: відсутні оцінки та неповні лічильники нагород не вигадуються. Оскари й загальні перемоги показуються лише за наявності явних підсумкових даних картки; вони не є додатковими рейтингами.

Запити виконуються для відкритої картки та видимих постерів головної й не блокують кнопки перегляду. Зберігаються максимум 180 записів на 24 години; після помилки — короткий кеш на 5 хвилин. Серіали й фільми мають окремі ключі, відповіді звіряються з IMDb ID. Відомості про відкритий IMDb ID передаються цим сервісам; історія, особисті оцінки, налаштування TorrServer та відео їм не надсилаються. Вимкнення «Рейтинги Faborn → Стандартні» вимикає нові запити. Стан останнього отримання оцінок є у «Версія та діагностика → Рейтинги».

**Список торрентів** отримав SVG-іконки й кольорові бейджі якості, формату, HDR / Dolby Vision, кодека, мов та звуку. Дані беруться з MediaInfo парсера або позначок назви релізу; це характеристики роздачі, а не обіцянка сумісності з телевізором. Виміряна роздільність має пріоритет над назвою. Відомості про озвучення та субтитри зі штатного списку збережені.

- **«Рекомендуємо»** — від 50 сідів за відповіддю парсера. Порядок роздач при цьому не змінюється; кількість сідів не гарантує швидкості.
- **Toloka / Гуртом** — позначка «Пріоритет» і кольорова смуга. Фокус пульта має окремий контрастний контур.
- Розмір виділено окремим бейджем; сіди, піри, бітрейт і дата розділені іконками. Невідома кількість сідів не перетворюється на нуль.
- **Налаштування → ukr by Faborn → Оформлення торрентів** повертає стандартний вигляд. Пошук, фільтри, сортування, наступні сторінки та запуск залишаються штатними; параметри парсера і TorrServer не змінюються.

## Головна, рейтинги та кнопки

На головній — **шість постерів у ряд** на телевізорі, назви під ними й рейтинги на постерах та один опис вибраного фільму над рядом. На вузькому екрані — два постери. Використовуються штатні завантаження каталогу, пошук, навігація і категорії Lampa.

У картці — один блок доступних **TMDB, IMDb, Rotten Tomatoes, Metacritic** зі шкалою відповідного сервісу: зірка IMDb, томат Rotten Tomatoes, логотипи TMDB і Metacritic. Поруч — статуетка «Оскар» та кубок загальної кількості перемог, якщо ці відомості передані в метаданих або наявними рейтинговими доповненнями. У beta.15 оцінки також доповнюються незалежними запитами, описаними вище. Відсутні оцінки й нагороди не вигадуються. **«Моя оцінка»** зберігає 1–10 на цьому пристрої; її можна змінити або прибрати. Спільного серверного рейтингу і синхронізації цих особистих оцінок немає.

**Бейджі якості** використовують знайдені онлайн-джерела та торрент-релізи за правилами вище. Для онлайн-серіалу вказано конкретну серію, наприклад S2E1. Наявність 4K сама по собі не означає HDR, Dolby Vision або багатоканальний звук.

**Налаштування → ukr by Faborn:** «Головний екран», «Рейтинги у картці» та «Бейджі якості Faborn» перемикаються окремо. Після зміни головної відкрий її повторно. «Оформлення модуля → Стандартне Lampa» вимикає оформлення Faborn, зберігаючи оцінки й вибрані параметри.

Нові рейтинги, бейджі та картки успадковують вибрану тему: у Faborn — її колір або градієнт, у iOS — скло зі щільнішою основою під текстом, у стандартній темі — нейтральне оформлення без кольорової підкладки. Зміни застосовуються одразу. Суцільного чорного фону під рейтингами немає.

### Кнопки та TorrServer

Синьо-жовта іконка відкриває онлайн-джерела. **Магніт** відкриває штатний пошук торрентів Lampa для поточного фільму або серіалу. Використовуються наявні налаштування парсера та TorrServer — модуль їх не перезаписує. TorrServer відтворює вибрану роздачу; для пошуку потрібен також налаштований парсер Lampa. Підпис на обох іконках прихований і при фокусі.

**Налаштування → ukr by Faborn → Порядок кнопок у картці** або довге натискання синьо-жовтої іконки: обери кнопку, потім її позицію. Порядок зберігається за постійними ідентифікаторами, окремо від номера версії. Спочатку відкрий будь-яку картку. Є відновлення початкового порядку; порожні кнопки та дубль видимої кнопки торрентів прибираються. Паралельні зовнішні редактори кнопок не потрібні.

### Джерела і плеєр

**UAKinogo / Alloha вимкнено**, зокрема якщо старе налаштування було увімкнене. Експериментального рядка, кнопки тесту і повідомлень цього джерела більше немає. **KinoBase залишається постійним джерелом**, його сесія й пряме відтворення збережені.

Під час перегляду **панель плеєра → Аудіодоріжки** дозволяє перемикати озвучення того самого джерела для поточної серії та якості зі збереженням таймкоду й паузи. Потік коротко перезавантажується. Прогрес серій, субтитри джерел і тема iOS залишаються доступними.

## Прозорість скла iOS — beta.13.2

**Налаштування → ukr by Faborn → Прозорість скла iOS.** Доступні «Непрозоре», «Низька», «Стандартна», «Висока» та «Максимальна». Налаштування працює у темі **iOS · Liquid Glass**, застосовується одразу до меню, вікон, кнопок картки та панелі керування плеєром і зберігається після перезапуску.

Типово вибрано «Стандартна» — попередній вигляд. Текст, іконки та фокус пульта залишаються чіткими: змінюються фони скла, а не прозорість цілого вікна. На рушіях без розмиття використовується щільніше скло. Інші теми й стандартне оформлення Lampa цей параметр не використовують.

## Сесія KinoBase — beta.13.1

На пристроях, де KinoBase відхиляє `/user_data` зі статусом HTTP 404, модуль повторює отримання списку через окрему сесію Samsung. Спочатку заново читається сторінка назви, потім сесія й плейлист — в одному сховищі cookie. Звичайний успішний запит додаткового адаптера не завантажує.

**Налаштування → ukr by Faborn → Сесія KinoBase → Автоматично** (типово). Для повернення попереднього способу є «Лише звичайний запит». Резервний спосіб потребує доступного Tizen Sockets у встановленому застосунку. Обробляються тільки метадані KinoBase на телевізорі; локальний порт не відкривається, відео передається AVPlay прямим посиланням. Окремий сервер не потрібен; перемикач експериментального 4K для цього не потрібний.

Якщо KinoBase недоступне, у списку джерел з’являється його стан і причина. Якщо потоки є в іншій якості, рядок підказує доступні якості. «Назад» скасовує запити та повертає фокус картці.

Для «Правдивої терапії» S2E1 живий тест тим самим C-кодом на macOS підтвердив: без cookie `/user_data` повертає 404, з cookie — 200, RU-доріжка до 1080p і доступний HLS. Перевірка на фізичному Samsung ще потрібна: наявність WebAssembly сама по собі не гарантує Tizen Sockets у конкретній збірці Lampa.

## Нова тема iOS · Liquid Glass — beta.13

**Налаштування → ukr by Faborn → Тема всієї Lampa → iOS · Liquid Glass.** Застосовується одразу та зберігається після перезапуску. Вигляд за замовчуванням не змінено.

Скляні поверхні, м’які відблиски й округлі кнопки оформлюють верхнє меню, бічну навігацію, кнопки картки, налаштування, списки вибору, діалоги, клавіатуру, сповіщення та елементи керування плеєром. У самому модулі так само оформлені «Панель», «Кінозал», якості, переклади й серії. Світлий фокус пульта відрізняється від вибраного кольорового пункту; колір акценту та обидва градієнти залишаються доступними.

Якщо було вибране «Стандартне Lampa», вибір iOS автоматично вмикає «Панель». Далі можна вибрати «Кінозал». Щоб повернути повністю штатний вигляд без кольорів, вибери **Оформлення модуля → Стандартне Lampa**; збережені тема й акцент не стираються.

На рушіях із підтримкою `backdrop-filter` працює розмиття за вікнами. Старі Tizen отримують щільніше скло з відблисками без розмиття. Ефекти не застосовуються до відеоплощини AVPlay; немає зовнішніх шрифтів, бібліотек чи додаткових мережевих запитів теми. Перевірено в браузері зі справжнім ядром Lampa; плавність на фізичному телевізорі ще потрібно оцінити.

## Оформлення

**Налаштування → ukr by Faborn:**

- **Оформлення модуля:** «Панель» — компактне вікно поверх картки; «Кінозал» — велике вікно з назвою, зображенням TMDB (якщо воно є) та описом. **«Стандартне Lampa»** — штатні списки джерел і серій та нейтральний фокус, без кольорових акцентів, градієнтів і глобальної теми Faborn. Додаткові функції працюють за власними перемикачами. Перемикання діє одразу. Раніше цей пункт називався «Стандартний список».
- **Тема всієї Lampa:** Faborn, iOS · Liquid Glass або стандартна Lampa. Для «Панелі» й «Кінозалу» окремо оформлює меню, кнопки картки, фокус постерів, налаштування, списки вибору й діалогові вікна. Вимкнення прибирає глобальні стилі Faborn без зміни налаштувань Lampa.
- **Колір акценту:** чотири суцільні кольори та два градієнти — **синій → фіолетовий** і **бірюзовий → синій**. У beta.9 градієнти насиченіші, з окремим контрастним кольором тексту. Градієнти застосовуються до кнопок, фокуса та смуг прогресу; Фокус кнопок позначений кольором без обводки. Акцент і глобальна тема застосовуються одразу; обраний вигляд модуля — під час наступного відкриття.

За замовчуванням: панель, тема Faborn, синій акцент. Для «Панелі» й «Кінозалу» глобальну тему можна перемикати окремо. «Стандартне Lampa» вимикає глобальну тему Faborn і надає додатковим блокам нейтральне оформлення; збережені колір і тема відновлюються при поверненні до «Панелі» або «Кінозалу». Власні налаштування Lampa та теми інших розширень не змінюються. Стилі модуля включені в головний JS-файл; оформлення головної, рейтингів і торрентів завантажується з `lib/faborn-ui.js` того самого GitHub Pages. Аналізатор KinoBase завантажується з того самого GitHub Pages; додаткові шрифти або сервер не потрібні. Тема оформлює Lampa, а не меню операційної системи Samsung. Відеоплощина Tizen залишається під керуванням Lampa.

## Перегляд

**Картка TMDB → синьо-жовта іконка → переклад або джерело → плеєр.** На кнопці модуля залишається тільки іконка; доступна назва для допоміжних технологій збережена. Велика кнопка «Дивитися» запускає перше джерело вибраного перекладу з урахуванням пріоритету джерела.

Модуль сам шукає українську й, за потреби, оригінальну назву на **UAKino, UASerials, UAFix та KinoBase**, перевіряє метадані сторінки й читає потоки. Якість обирається кнопками у тому самому вікні. Нижче — по одному рядку на переклад. Українські доріжки позначені **UA**, російські — **🐷 RU**; у «Панелі» та «Кінозалі» іконка векторна й не залежить від підтримки емодзі телевізором. Підтверджені англійські доріжки позначені EN. Порядок мов: UA, EN, оригінал невідомою мовою, RU. Напис «Оригінал» стає EN лише за наявності англійської оригінальної мови в TMDB. Однакові назви перекладів однією мовою згруповані між джерелами; номер плеєра не створює окремого перекладу. Якщо джерело одне, натискання запускає його. Якщо кілька — кнопки джерел розгортаються під перекладом; натискання джерела одразу запускає його.

Якість запам’ятовується. За замовчуванням — найвища доступна; якщо збереженої якості немає, обирається найближча нижча або найнижча доступна. Перемикання якості змінює перелік доступних перекладів без повторного пошуку. 4K показується лише для наявного 2160p. «Назад» закриває вікно й повертає керування картці.

Для серіалу є окремі кнопки **«Сезон …»** та **«Серія …»**. Модуль запам’ятовує останню фактично переглянуту серію; саме відкриття списку або невдалий запуск її не змінює. Наступна серія поки обирається вручну; неперевірені посилання не додаються до автоплейлиста. За наявності прогресу Lampa він показується у вікні. «Продовжити з …» з'являється лише коли в плеєрі увімкнено продовження та запис ще не переглянутий до кінця; глобальний режим тайм-коду не змінюється.

### Серії та історія

Натисни **«Серія …»**: у «Панелі» та «Кінозалі» відкриються кадри, назви й короткі описи TMDB. Для кожного епізоду показані таймкод, смуга прогресу або «Переглянуто» від 90%. У стандартному списку також є кадри, назви, короткі описи та текстовий прогрес. Відсутність кадру чи відповіді TMDB не блокує вибір епізоду.

**«Ви дивилися S…E…»** повертає до останньої переглянутої серії, навіть після перегляду іншого сезону в меню. Прогрес окремий для кожного епізоду та спільний між озвученнями й джерелами. Збережені таймкоди beta.9 читаються; нові позначки також передаються стандартній історії Lampa. Запис додається до **Історії Lampa** після фактичного початку відео, прогрес зберігається приблизно кожні 15 секунд та при виході. Синхронізацію між пристроями визначає сама Lampa.

### Субтитри

Доступні доріжки вибираються кнопкою **CC / «Субтитри» у плеєрі Lampa**. Якщо джерело віддало зовнішні доріжки, їхні назви видно під кнопкою запуску. Підтримано SRT/VTT із відкритих конфігурацій, успадкування субтитрів зі списків сезонів і нативні доріжки HLS. Порожній список більше не перекриває субтитри Tizen. Якщо джерело їх не надає, модуль не створює й не перекладає субтитри автоматично.

### Англійський оригінал

Beta.10 показує EN там, де наявне джерело справді віддає англійську доріжку. **Нового окремого англомовного сервісу в цій версії ще немає.** У переглянутих адаптерах VidSrc/VidLink/Videasy потік отримується через браузерний обробник на сервері, а відкриті сторінки VidSrc повернули iframe; HDRezka повернув перевірку браузера на сторінці фільму. Прямий HLS для нашої схеми «GitHub Pages → Tizen» з нового сервісу не підтверджений. У перевірених KinoBase «Оппенгеймері», «Друзях», The Office, The Big Bang Theory та Stranger Things англійська доріжка не знайдена.

Зіставлення виконується за українською/оригінальною назвою, типом і роком. Різниця року до одного враховує прокатні дати. Рік пізнішого сезону UAKino може відрізнятися від року початку серіалу TMDB. Приблизний збіг із пошуку додатково перевіряється за повною сторінкою, щоб не запустити інший фільм.

## Джерела

| Джерело | Підтримка |
|---|---|
| UAKino | Пошук, сторінки фільмів/сезонів, AJAX-списки відео, українські озвучення |
| UASerials | Пошук, HDVB UA, вкладені списки сезонів/серій/озвучень |
| UAFix | Пошук, фільми, сторінки сезонів і окремих епізодів; показ тільки доступних потоків |
| KinoBase | Постійний пошук, прямий плеєр, UA/RU, сезони й серії; до 2160p там, де воно доступне |
| KinoUkr | Резервні перевірені записи GitHub-індексу; загального пошуку KinoUkr немає |

Відкриті конфігурації Playerjs: Ashdi, HDVB UA, Zetvideo, Tortuga. Підтримано прямий HLS і вкладені JSON-списки без виконання коду сайтів. Невідомі формати й перевірки доступу не обходяться. Наявність адаптера не гарантує доступності конкретного плеєра.

**На 30.09.2026:** для «Проєкт Аве Марія» й «Ззовні» на UASerials перевірено відповіді HLS і відеосегментів 1080p. Два перевірені плеєри UAFix / Zetvideo повернули 404. Недоступні варіанти не позначаються як готові до відтворення. Це не оцінка всього каталогу UAFix.

Якість визначається з маніфесту або явного списку варіантів плеєра. Напис 4K з'являється лише за наявності 2160p; HDR не вгадується. Мова підтверджується метаданими сторінки/озвучення, а не автоматичним розпізнаванням звуку.

### KinoBase

Публічний плеєр KinoBase працює через анонімну cookie-сесію. У beta.10 сторінки кандидатів читаються послідовно: одночасне відкриття схожих фільмів замінювало cookie й давало HTTP 404, зокрема для «Оппенгеймера». Модуль читає актуальні параметри запитів зі структури JS, отримує HLS та оновлює тимчасові посилання перед запуском, якщо минула хвилина. Кеш одного списку живе тільки в пам’яті. Оновлення зберігає конкретне озвучення, сезон і серію; зникла доріжка не замінюється іншою мовою. Дзеркала не дублюються у вікні й перевіряються по черзі при помилці.

Для HLS з окремим аудіо плеєру передається повний master-плейлист. KinoBase може мати окремі master-посилання для кожної якості й аудіодоріжки. Це зберігає звук та ручний вибір якості.

Не всі сторінки KinoBase містять прямий плеєр: сторонні iframe-балансери поки не підтримуються. Зміна протоколу сайту, cookie-обмеження, мережеві блокування або несумісний кодек можуть зробити конкретне відео недоступним. Це відображається в діагностиці й не блокує інші джерела.

**Перевірено 30.09.2026 кодом beta.9:** «Термінатор 2» — 3840×2160 з окремою аудіодоріжкою; «Назад у майбутнє» — 1920×1040; «Друзі» — 10 сезонів, 1280×720, зокрема UA 1+1 та RU Paramount Comedy/РТР. Мова визначена з назв доріжок; перевірка HLS не замінює перегляд на фізичному телевізорі.

## Навігація та помилки

«Назад» скасовує запити й повертає керування картці. Повторний пошук, перехід між сезонами та запізнілі мережеві відповіді не повинні залишати фокус у прихованому меню. Перед запуском плеєра також відновлюється контролер картки, щоб його закриття повертало користувача до Lampa.

Окремий запит має таймаут 12 секунд; загальний пошук обмежений 24 секундами, перевірка обраної серії — 20 секундами. Показуються отримані робочі варіанти; відмова одного джерела не скасовує інші. Посилання, старше хвилини, повторно читається з плеєра. Маніфест вибраної якості перевіряється безпосередньо перед запуском.

Діагностика доступна в налаштуваннях, без додаткового мережевого запиту: версія, плеєр, AVPlay, стан джерел, останні етапи пошуку та помилка відтворення. Відомості зберігаються локально в Lampa. Якщо відео не запустилося за 45 секунд, є повтор і вибір іншого джерела/якості. Глобальні налаштування плеєра не змінюються.

## GitHub

GitHub Pages віддає головний JS, `lib/faborn-ui.js`, `lib/kinobase.js` і резервний JSON. Аналізатор використовує зафіксований Acorn 8.18.0 (MIT), розміщений у цьому ж репозиторії; код стороннього плеєра не виконується. При ручному копіюванні обов’язково зберігай каталог `lib/`. Пошук і читання нових сторінок виконує телевізор; відео надходить із відеохостів. Для онлайн-джерел проксі, VPS або TorrServer не потрібні. Окрема кнопка торрентів використовує налаштований користувачем TorrServer. GitHub не виконує запити на вимогу телевізора.

Резервний індекс із 3 назв («Бджоляр», «Профі», «Річер», сезон 3) автоматично доповнює результати відповідних карток. Він не обмежує пошук цими назвами. Actions оновлює його після push та приблизно кожні 30 хвилин. Кнопка «Оновити індекс із GitHub» читає готовий JSON і не запускає Actions.

Для власної копії: завантаж файли разом із `.github/`, увімкни **Settings → Pages → Source → GitHub Actions**, дочекайся build/deploy. Головна сторінка Pages покаже адресу JS. Для відкату поверни файли попереднього релізу та опублікуй Pages.

## Перевірки

Python 3.10+, Node.js 20+, C-компілятор і заголовки/бібліотека libcurl для перевірок локального каналу; без додаткових pip/npm залежностей. На Ubuntu потрібен `libcurl4-openssl-dev`; на macOS достатньо Command Line Tools. SDK Samsung потрібен лише для повторної збірки WASM:

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/build_resolver.py
node --test tests/test_*.js
node --check ukr-by-faborn.js
python3 scripts/validate.py
```

Докази та межі перевірки — `VALIDATION.md`. Користувач підтвердив роботу beta.6 на телевізорі. Оформлення та навігацію beta.9 перевірено у справжньому ядрі Lampa з контрольованими відповідями джерел; новий адаптер потребує перевірки на фізичному Samsung. Браузерна перевірка не замінює Tizen / AVPlay.
