# ukr by Faborn — 0.1.0-beta.12.2

Розширення Lampa для Samsung Tizen. Код і резервний індекс розміщені на GitHub Pages; окремий сервер не потрібен. Відео відтворюється через Tizen / AVPlay.

## Оновлення

Повністю перезапусти Lampa. Адреса встановленого розширення залишається та сама, зокрема зі старим `?v=…`:

```text
https://serg-ill.github.io/ukr-by-faborn/ukr-by-faborn.js
```

Версія: **Налаштування → ukr by Faborn → Версія та діагностика → 0.1.0-beta.12.2**. Додавати другу копію чи повторно вводити посилання не потрібно.

## Експериментальне джерело у картці — beta.12.2

**Налаштування → ukr by Faborn → Експериментальне 4K → Увімкнено. Потім відкрий картку фільму чи серіалу → іконка модуля.**

Тепер перемикач додає **UAKinogo / Alloha до пошуку саме відкритої картки**. У beta.12/12.1 він дозволяв тільки окремий ручний тест «Оппенгеймера» — це виправлено. Новий пошук використовує оригінальну та локалізовану назву, перевіряє рік і відрізняє фільм від однойменного серіалу. Сайт `.io` перевіряється як резервне дзеркало `.is`, без дублювання джерела.

Знайдені озвучення UA/EN/RU з’являються у звичних групах, разом із доступними якостями. Для серіалів використовуються ті самі кнопки сезону й серії, назви TMDB та історія. Перед запуском вибране озвучення оновлюється, роздільність перевіряється за HLS, а перший відеосегмент — запитом до відеосервера. Відсутня доріжка не замінюється іншою мовою. Нижчі якості також показуються: джерело не обмежується лише 4K.

Окремий рядок **«UAKinogo / Alloha · експеримент»** показує поточний етап, результат або причину відмови прямо у картці. Натискання відкриває деталі й повторний пошук лише цього джерела. Звичайні джерела не чекають завершення нового адаптера. Режим початково вимкнений; у вимкненому стані додатковий код і мережевий адаптер не завантажуються. Кнопка «Перевірити 4K» у налаштуваннях лишається додатковим тестом «Оппенгеймера».

Адаптер WebAssembly/cURL завантажується з GitHub Pages і працює у Worker на самому телевізорі. Він передає відео AVPlay через локальний порт `127.0.0.1` зі випадковою адресою сесії. Відео не проходить через GitHub, Ubuntu, VPS або сторонній проксі. Потрібні **Tizen Sockets / WebAssembly (Tizen 5.5+) і Tizen / AVPlay**. Доступність API залежить також від встановленої збірки Lampa. «Назад» скасовує очікування й повертає керування; незавершений нативний запит має обмежений час завершення.

Живі перевірки 30.09.2026 з тим самим C-кодом на macOS: **«Оппенгеймер» і «Джентльмени» S1E1 — UA/EN/RU, 3840×2160, AV1; «Друзі» S1E1 — UA/EN/RU, 1920×1080, H.264**. Для «Друзів» прочитано список 234 серій; їхні потоки не перевірялися всі. **Фізичне відтворення через новий адаптер на Samsung ще не підтверджене.** Для перевірених 4K-потоків потрібна апаратна підтримка AV1; перекодування немає. HDR, субтитри нового джерела й покриття всього каталогу не гарантовані.

### Збірка додаткового адаптера

Для звичайного встановлення потрібне лише стандартне посилання на JS. Бінарний модуль уже включено до Pages. Його джерело — `src/4klab/native.c`; збірка — `scripts/build_4klab.py` з офіційним Samsung Emscripten 1.39.4.7 і Python 3.9. Скрипт містить дві локальні поправки до компілятора SDK: C++17 для його constexpr-лямбд та передавання host-import імен у upstream backend. Використано штатний шлях Tizen SocketsManager (`SOCKET_HOST_BINDINGS=0`), без WebSocket-проксі. Залежності та ліцензії: `lib/4klab/LICENSES.txt`; CA-сертифікати Mozilla з curl.se, перевірку TLS увімкнено. Максимальна пам’ять WASM — 128 MiB, одна активна передача, відповідь обмежена 16 MiB. URL, редиректи та HLS URI перевіряються за окремим списком дозволених серверів.

## Оформлення

**Налаштування → ukr by Faborn:**

- **Оформлення модуля:** «Панель» — компактне вікно поверх картки; «Кінозал» — велике вікно з назвою, зображенням TMDB (якщо воно є) та описом. **«Стандартне Lampa»** — штатні списки, вікна й фокус Lampa, без кольорових акцентів, градієнтів та глобальної теми Faborn. Перемикання діє одразу. Раніше цей пункт називався «Стандартний список».
- **Тема всієї Lampa:** Faborn або стандартна Lampa. Для «Панелі» й «Кінозалу» окремо оформлює меню, кнопки картки, фокус постерів, налаштування, списки вибору й діалогові вікна. Вимкнення прибирає глобальні стилі Faborn без зміни налаштувань Lampa.
- **Колір акценту:** чотири суцільні кольори та два градієнти — **синій → фіолетовий** і **бірюзовий → синій**. У beta.9 градієнти насиченіші, з окремим контрастним кольором тексту. Градієнти застосовуються до кнопок, фокуса та смуг прогресу; Фокус кнопок позначений кольором без обводки. Акцент і глобальна тема застосовуються одразу; обраний вигляд модуля — під час наступного відкриття.

За замовчуванням: панель, тема Faborn, синій акцент. Для «Панелі» й «Кінозалу» глобальну тему можна перемикати окремо. «Стандартне Lampa» вимикає всі стилі оформлення Faborn; збережені колір і тема відновлюються при поверненні до «Панелі» або «Кінозалу». Власні налаштування Lampa та теми інших розширень не змінюються. Усі стилі включені в головний JS-файл. Аналізатор KinoBase завантажується з того самого GitHub Pages; додаткові шрифти або сервер не потрібні. Тема оформлює Lampa, а не меню операційної системи Samsung. Відеоплощина Tizen залишається під керуванням Lampa.

## Перегляд

**Картка TMDB → синьо-жовта іконка → переклад або джерело → плеєр.** На кнопці модуля залишається тільки іконка; доступна назва для допоміжних технологій збережена. Велика кнопка «Дивитися» запускає перше джерело вибраного перекладу з урахуванням пріоритету джерела.

Модуль сам шукає українську й, за потреби, оригінальну назву на **UAKino, UASerials, UAFix та KinoBase**, перевіряє метадані сторінки й читає потоки. Якість обирається кнопками у тому самому вікні. Нижче — по одному рядку на переклад. Українські доріжки позначені **UA**, російські — **🐷 RU**; у «Панелі» та «Кінозалі» іконка векторна й не залежить від підтримки емодзі телевізором. Підтверджені англійські доріжки позначені EN. Порядок мов: UA, EN, оригінал невідомою мовою, RU. Напис «Оригінал» стає EN лише за наявності англійської оригінальної мови в TMDB. Однакові назви перекладів однією мовою згруповані між джерелами; номер плеєра не створює окремого перекладу. Якщо джерело одне, натискання запускає його. Якщо кілька — кнопки джерел розгортаються під перекладом; натискання джерела одразу запускає його.

Якість запам’ятовується. За замовчуванням — найвища доступна; якщо збереженої якості немає, обирається найближча нижча або найнижча доступна. Перемикання якості змінює перелік доступних перекладів без повторного пошуку. 4K показується лише для наявного 2160p. «Назад» закриває вікно й повертає керування картці.

Для серіалу є окремі кнопки **«Сезон …»** та **«Серія …»**. Модуль запам’ятовує останню фактично переглянуту серію; саме відкриття списку або невдалий запуск її не змінює. Наступна серія поки обирається вручну; неперевірені посилання не додаються до автоплейлиста. За наявності прогресу Lampa він показується у вікні. «Продовжити з …» з'являється лише коли в плеєрі увімкнено продовження та запис ще не переглянутий до кінця; глобальний режим тайм-коду не змінюється.

### Серії та історія

Натисни **«Серія …»**: у «Панелі» та «Кінозалі» відкриються кадри, назви й короткі описи TMDB. Для кожного епізоду показані таймкод, смуга прогресу або «Переглянуто» від 90%. У стандартному списку залишаються текстові назви та прогрес. Відсутність кадру чи відповіді TMDB не блокує вибір епізоду.

**«Ви дивилися S…E…»** повертає до останньої переглянутої серії, навіть після перегляду іншого сезону в меню. Прогрес окремий для кожного епізоду та спільний між озвученнями й джерелами. Збережені таймкоди beta.9 читаються; нові позначки також передаються стандартній історії Lampa. Запис додається до **Історії Lampa** після фактичного початку відео, прогрес зберігається приблизно кожні 15 секунд та при виході. Синхронізацію між пристроями визначає сама Lampa.

### Субтитри

Доступні доріжки вибираються кнопкою **CC / «Субтитри» у плеєрі Lampa**. Якщо джерело віддало зовнішні доріжки, їхні назви видно під кнопкою запуску. Підтримано SRT/VTT із відкритих конфігурацій, успадкування субтитрів зі списків сезонів і нативні доріжки HLS. Порожній список більше не перекриває субтитри Tizen. Якщо джерело їх не надає, модуль не створює й не перекладає субтитри автоматично.

### Англійський оригінал

Beta.10 показує EN там, де наявне джерело справді віддає англійську доріжку. **Нового окремого англомовного сервісу в цій версії ще немає.** У переглянутих адаптерах VidSrc/VidLink/Videasy потік отримується через браузерний обробник на сервері, а відкриті сторінки VidSrc повернули iframe; HDRezka повернув перевірку браузера на сторінці фільму. Прямий HLS для нашої схеми «GitHub Pages → Tizen» з нового сервісу не підтверджений. У перевірених KinoBase «Оппенгеймері», «Друзях», The Office, The Big Bang Theory та Stranger Things англійська доріжка не знайдена.

Зіставлення виконується за українською/оригінальною назвою, типом і роком. Різниця року до одного враховує прокатні дати. Рік пізнішого сезону UAKino може відрізнятися від року початку серіалу TMDB. Приблизний збіг із пошуку додатково перевіряється за повною сторінкою, щоб не запустити інший фільм.

| Джерело | Підтримка |

| UAKino | Пошук, сторінки фільмів/сезонів, AJAX-списки відео, українські озвучення |

Відкриті конфігурації Playerjs: Ashdi, HDVB UA, Zetvideo, Tortuga. Підтримано прямий HLS і вкладені JSON-списки без виконання коду сайтів. Невідомі формати й перевірки доступу не обходяться. Наявність адаптера не гарантує доступності конкретного плеєра.

**На 30.09.2026:** для «Проєкт Аве Марія» й «Ззовні» на UASerials перевірено відповіді HLS і відеосегментів 1080p. Два перевірені плеєри UAFix / Zetvideo повернули 404. Недоступні варіанти не позначаються як готові до відтворення. Це не оцінка всього каталогу UAFix.

Якість визначається з маніфесту або явного списку варіантів плеєра. Напис 4K з'являється лише за наявності 2160p; HDR не вгадується. Мова підтверджується метаданими сторінки/озвучення, а не автоматичним розпізнаванням звуку.

### KinoBase

Публічний плеєр KinoBase працює через анонімну cookie-сесію. У beta.10 сторінки кандидатів читаються послідовно: одночасне відкриття схожих фільмів замінювало cookie й давало HTTP 404, зокрема для «Оппенгеймера». Модуль читає актуальні параметри запитів зі структури JS, отримує HLS та оновлює тимчасові посилання перед запуском, якщо минула хвилина. Кеш одного списку живе тільки в пам’яті. Оновлення зберігає конкретне озвучення, сезон і серію; зникла доріжка не замінюється іншою мовою. Дзеркала не дублюються у вікні й перевіряються по черзі при помилці.

Для HLS з окремим аудіо плеєру передається повний master-плейлист. KinoBase може мати окремі master-посилання для кожної якості й аудіодоріжки. Це зберігає звук та ручний вибір якості.

Не всі сторінки KinoBase містять прямий плеєр: сторонні iframe-балансери поки не підтримуються. Зміна протоколу сайту, cookie-обмеження, мережеві блокування або несумісний кодек можуть зробити конкретне відео недоступним. Це відображається в діагностиці й не блокує інші джерела.

**Перевірено 30.09.2026 кодом beta.9:** «Термінатор 2» — 3840×2160 з окремою аудіодоріжкою; «Назад у майбутнє» — 1920×1040; «Друзі» — 10 сезонів, 1280×720, зокрема UA 1+1 та RU Paramount Comedy/РТР. Мова визначена з назв доріжок; перевірка HLS не замінює перегляд на фізичному телевізорі.

## Навігація та помилки

«Назад» скасовує запити й повертає керування картці. Повторний пошук, перехід між сезонами та запізнілі мережеві відповіді не повинні залишати фокус у прихованому меню. Перед запуском плеєра також відновлюється контролер картки, щоб його закриття повертало користувача до Lampa.

Окремий запит має таймаут 12 секунд; загальний пошук обмежений 24 секундами, перевірка обраної серії — 20 секундами. Показуються отримані робочі варіанти; відмова одного джерела не скасовує інші. Посилання, старше хвилини, повторно читається з плеєра. Маніфест вибраної якості перевіряється безпосередньо перед запуском.

Діагностика доступна в налаштуваннях, без додаткового мережевого запиту: версія, плеєр, AVPlay, стан джерел, останні етапи пошуку та помилка відтворення. Відомості зберігаються локально в Lampa. Якщо відео не запустилося за 45 секунд, є повтор і вибір іншого джерела/якості. Глобальні налаштування плеєра не змінюються.

## GitHub

GitHub Pages віддає головний JS, `lib/kinobase.js` і резервний JSON. Аналізатор використовує зафіксований Acorn 8.18.0 (MIT), розміщений у цьому ж репозиторії; код стороннього плеєра не виконується. При ручному копіюванні обов’язково зберігай каталог `lib/`. Пошук і читання нових сторінок виконує телевізор; відео надходить із відеохостів. Проксі, VPS або TorrServer не потрібні. GitHub не виконує запити на вимогу телевізора.

Резервний індекс із 3 назв («Бджоляр», «Профі», «Річер», сезон 3) автоматично доповнює результати відповідних карток. Він не обмежує пошук цими назвами. Actions оновлює його після push та приблизно кожні 30 хвилин. Кнопка «Оновити індекс із GitHub» читає готовий JSON і не запускає Actions.

Для власної копії: завантаж файли разом із `.github/`, увімкни **Settings → Pages → Source → GitHub Actions**, дочекайся build/deploy. Головна сторінка Pages покаже адресу JS. Для відкату поверни файли попереднього релізу та опублікуй Pages.

## Перевірки

Python 3.10+, Node.js 20+, C-компілятор і заголовки/бібліотека libcurl для перевірок локального каналу; без додаткових pip/npm залежностей. На Ubuntu потрібен `libcurl4-openssl-dev`; на macOS достатньо Command Line Tools. SDK Samsung потрібен лише для повторної збірки WASM:

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/build_resolver.py
node --test tests/test_*.js
node --check ukr-by-faborn.js
python3 scripts/validate.py
```

Докази та межі перевірки — `VALIDATION.md`. Користувач підтвердив роботу beta.6 на телевізорі. Оформлення та навігацію beta.9 перевірено у справжньому ядрі Lampa з контрольованими відповідями джерел; новий адаптер потребує перевірки на фізичному Samsung. Браузерна перевірка не замінює Tizen / AVPlay.
